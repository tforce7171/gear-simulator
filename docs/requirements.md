# Gear Simulator 要件定義

3D 空間で歯車を自由に組み、がっちりかみ合ってくるくる回るのを眺めるブラウザ玩具。

- 策定日: 2026-10-27

## 1. コンセプト

- **サンドボックス型の玩具**。ゴールやステージはない。
- 差別化
  - **かみ合わせが必ず成立する手軽さ**と、**インボリュート歯形による本物らしい見た目**の両立。手で位置を合わせる難しさや、物理演算で詰まる・振動する問題を構造的に起こさない。
  - **作り込んだ機械音**
  - **鑑賞のための機能**（眺めるモード）

## 2. 対象と規模

- 主対象は PC のブラウザ。タッチ操作は後から追加しやすいよう、入力は Pointer Events で書く。
- 性能目標: 歯車 200 個を、普通のノート PC で 60fps。
- 当面はローカルで起動できればよい（`pnpm dev`）。公開方法は未定。
- サーバーは持たない。静的サイトとして完結させる。

## 3. 部品

### 3.1 歯車の種類

| 種類 | つなぐ軸 | 段階 |
|---|---|---|
| 平歯車 | 平行 | 1 |
| ハスバ歯車 | 平行 | 2 |
| かさ歯車 | 交わる 90° のみ（歯数比 1:1 のみ） | 2 |
| ウォームギア（ウォーム + ホイール） | ねじれた位置の 90° | 2 |
| ねじ歯車 | ねじれた位置の 90° のみ | 2 |
| 内歯車 | 同軸・平行 | 3 |
| 遊星歯車（太陽歯車・遊星歯車・リング・キャリア） | 同軸 | 3 |
| ラック＆ピニオン | 回転 ↔ 直線 | 3 |

対象外: チェーン、ベルト

段階 2・3 の部品の決まった値:

| 部品 | 値 |
|---|---|
| ハスバ歯車 | ねじれ角 20°。モジュールは軸直角モジュールとして扱い、中心距離は平歯車と同じ。ねじれの向きが逆の組だけかみ合う |
| ねじ歯車 | ねじれ角 45° |
| ウォーム | 1 条、右ねじ。ピッチ円直径 10m（m はモジュール）、長さ 5 ピッチ |
| 内歯車 | 歯数 24 以上。かみ合う外歯車との歯数差 12 以上 |
| ラック | 端の余白 1 ピッチ。端に向かって押している間はロックし、逆向きに駆動されれば解ける |
| 固定具 | シャフトに付ける（歯車を固定すると、そのシャフトを固定する） |

### 3.2 歯の大きさと歯数

- 歯の大きさ（モジュール）は **大・中・小の 3 種類**。
- **かみ合えるのは同じ大きさ同士だけ**。大きさが違う歯車へは、同じシャフトに重ねて動力を受け渡す。
- 歯数は、大きさごとに決めた範囲で変えられる。
- 長さの単位は 1 = 1 mm。圧力角は 20°。歯元は簡略化して描く（切り下げは再現しない）。

| 大きさ | モジュール | 歯幅 | 歯数の範囲 |
|---|---|---|---|
| 小 | 1 | 4 | 12〜80 |
| 中 | 2 | 8 | 12〜60 |
| 大 | 3 | 12 | 12〜40 |

### 3.3 その他の部品

- **シャフト**: 独立した部品。複数の歯車を通せる。長さは載っている部品に合わせて自動で伸び縮みする。
- **モーター**: 小・中・大の 3 種類。シャフトに取り付ける。速度（無負荷回転数）、向き、ON/OFF を設定できる。取り付けと取り外しは、プロパティパネルとコンテキストメニューから行う。
- **固定具（アンカー）**: シャフトや歯車を地面に固定し、回らなくする。段階 3 で入れる。
- **キャリア**: 遊星歯車の軸を持って公転させる腕。
- 支柱やフレームは不要。部品は空中に浮いてよい（重力はない）。

## 4. 空間

- グリッドのある床がある。床は見た目と基準のためだけにあり、重力はない。
- 全ての軸の向きは **縦・横 X・横 Z の 3 方向のいずれか**。かさ歯車とねじ歯車を 90° に限ったため、この 3 方向で閉じる。

## 5. 回転の計算モデル

- **物理演算は使わない**。運動学と準静的な力のつり合いで計算する。
- かみ合った歯車の速度比は歯数比で決まる。かみ合う歯の位相も合わせる。
- **モーター**: 停動トルクと無負荷回転数を持ち、トルクは速度に対して直線的に下がる（T = 停動トルク × (1 − ω／無負荷回転数)）。停動トルクは大きさごとに固定、無負荷回転数はユーザーが設定する。

| 大きさ | 停動トルク（相対値） | 無負荷回転数の範囲 | 初期値 |
|---|---|---|---|
| 小 | 1 | 1〜120 rpm | 60 rpm |
| 中 | 3 | 1〜120 rpm | 30 rpm |
| 大 | 10 | 1〜120 rpm | 15 rpm |

- つながった歯車群ごとに、ギア比を考えた力のつり合いを **一次方程式で解いて** 速度を決める。
  - 逆向きのモーター同士は強いほうの向きに回るが、単独より遅くなる。負けたモーターは逆に回される。
  - 同じ向きで設定速度が違う場合は、中間の速度になる。
  - ギア比はてこになる。小さいモーターでも、大きく減速すれば大きいモーターに勝てる。
- **ロック**（震えて赤く光る）になる条件:
  - 強さが同じモーターが逆向きに回そうとして、速度 0 でつり合う（|ω| < 1e-6 rad/s で、少なくとも 1 つのモーターがトルクを出している状態）
  - 3 つの歯車が三角形にかみ合うなど、回転条件が矛盾する（方程式の解の有無で厳密に判定する）。偶然ちょうどの距離に来たかみ合いは、歯の位相が合っていなくても拘束として扱う
  - ウォームギアをホイール側から駆動しようとする（強さに関係なく）
  - ラックが端に達する
  - 固定具と矛盾する
- **自由度**: 遊星歯車機構のように自由度が 2 以上ある機構も、同じ方程式の仕組みで解く。どこからも駆動されていない部分は止まったまま。
- **慣性はなし**（準静的）。モーターを ON にすると即座に定常速度になり、OFF にすると即座に止まる。速度を状態として持てる構造にし、後から慣性を追加できるようにしておく。
- **手で回す**: 手の力は無限に強いものとして扱う。歯車群は手の位置に完全に追従し、手を離すと即座にモーター同士のつり合いの速度に戻る。

## 6. 配置と編集

- **既存の歯車から生やす**方式。歯車を選ぶと、かみ合わせられる場所の候補が表示される（外周、同じ軸、かさ歯車・ウォームでの 90°）。候補をクリックすると、正しい位置・向き・位相で自動的に置かれる。候補には、同じ大きさで干渉しないものだけを出す。外周の候補では新しいシャフトを自動で作り、同じ軸の候補では既存のシャフトに通す。
- **起点のシャフト**: 部品パレットから床へドラッグして置く。向きは R キーで切り替える。高さと位置はハンドルで調整する。起点は何本でも置ける。
- **外周の候補**: 45° 刻みの 8 方向に出す。細かい角度は円弧ハンドルで調整する。
- **外周の角度**: 選択したときに出る円弧状のハンドルで、親の歯車の周りを連続的に動かす。別の歯車とちょうどかみ合う角度に吸着し、ループを作れる。
- **シャフト上の位置**: ドラッグで動かし、4 mm の格子（最小の歯幅）に吸着させる。
- **変更の伝わり方**: 歯数や角度を変えると、その先につながっている歯車が全部ついてくる（木構造として位置を計算し直す）。ループ状に閉じた接続で辻褄が合わなくなった部分は切り離す。
- **削除**: 途中の歯車を消すと、その先はその場に残る（どこにもつながらず浮いた状態になる）。浮いたシャフトをドラッグして別の歯車の外周候補の上で離すと、その先ごとつなぎ直せる。
- **干渉**: 重なる配置は置けない。編集の連鎖で重なった場合は赤く警告する。判定は歯車を円柱、シャフトを線分で近似した簡易計算で行う。
- **Undo/Redo** あり。

## 7. 操作

### 7.1 マウス

| 操作 | 内容 |
|---|---|
| 歯車の上で左ドラッグ | 手で回す |
| 何もない所で左ドラッグ／右ドラッグ／Alt+左ドラッグ | カメラ回転（Alt を押していれば歯車の上でも回転） |
| 中ドラッグ／Shift+右ドラッグ／Space+ドラッグ | 平行移動 |
| ホイール | カーソル位置に向かってズーム |
| ダブルクリック | そこを回転の中心にして寄る |
| 右クリック（ドラッグなし） | コンテキストメニュー |

- コンテキストメニューの中身
  - 部品の上: 削除、モーターを付ける／外す（シャフト）、ここに寄る
  - 何もない所: 全体表示、眺めるモードの ON/OFF、情報表示の ON/OFF

- **Mac のトラックパッド**: ピンチでズーム、2 本指スクロールで平行移動。2 本指スクロールの割り当ては設定で変えられる。
- マウスとトラックパッドは自動で判別するが、入力デバイスを手動で固定する設定も付ける。
- 視点の切り替え: 画面隅の軸の目印と、テンキーの 1/3/7（Ctrl で反対側）。テンキーの 5 で透視投影と平行投影を切り替える。
- 眺めるモード: 自動でゆっくり周回する。

### 7.2 キーボード

| キー | 内容 |
|---|---|
| Delete | 削除 |
| Ctrl+Z／Ctrl+Shift+Z | 元に戻す／やり直し |
| Space（押して離す） | 全モーターの一時停止 |
| Space+ドラッグ | 平行移動 |
| F | 選択中の物に寄る（未選択なら全体） |
| Home | 全体表示 |
| R | 向きの切り替え |
| M | ミュート |
| Esc | 選択の解除 |

### 7.3 情報表示

- rpm・ギア比・回転方向の矢印を表示できる。ON/OFF で切り替え、標準は OFF（選択中の歯車だけ表示）。

### 7.4 画面の配置

- 左に部品パレット、右にプロパティパネル、上にツールバー（作品一覧、保存、エクスポート、インポート、テーマ、情報表示、ミュート、設定）、右下に軸の目印。
- 設定画面: 品質（高品質／軽量）、入力デバイス、2 本指スクロールの割り当て、言語、テーマ。

## 8. 見た目

- テーマは **真鍮** と **木製** の 2 つ。標準は真鍮。テーマで見た目と音の材質の両方が変わる。
- 質感は PBR（物理ベース）＋環境マップの反射＋影。設定で「高品質／軽量」を切り替えられる。
- 歯形はインボリュート曲線から実行時に生成する。歯数と大きさが同じ歯車は形状データを共有する。

## 9. 音

- **Web Audio で合成**するリアルな機械音。録音した音源は使わない。
- **材質**はテーマに合わせる（真鍮なら金属音、木製ならコトコト音）。
- **歯が通過する頻度**（歯数×回転数）で音が変わる。遅いとカチカチ、速いとうなり。
- 音源はかみ合っている箇所ごとに置き、3D 空間に配置する（近づくとその箇所の音がよく聞こえる）。
- 同時に鳴らすのは、カメラに近い最大 16 個まで。残りはまとめて背景のうなり音にする。
- 専用の音を作るもの: ロックしたとき、モーターが負けて逆に回されているとき、モーターのうなり。
- ミュートあり。音はユーザーが操作した後に開始する。

## 10. 保存

- **IndexedDB** に、サムネイル付きの作品一覧と自動保存を持つ。
  - 自動保存: 変更から 1 秒後にまとめて（デバウンス）「自動保存」枠に書き、起動時にそこから復元する。
  - 作品一覧への保存はユーザーが明示的に行う。サムネイルはその時点の画面から 256×256 の PNG を作る。
- 設定（品質、入力デバイス、言語、テーマ、ミュート）は localStorage に保存する。
- **JSON ファイルへのエクスポートとインポート**ができる。形式にはバージョン番号を付ける。
- URL での共有はしない。

## 11. 国際化

- 日本語と英語の 2 言語に対応する。

## 12. 技術

| 項目 | 採用するもの |
|---|---|
| 言語・ビルド | TypeScript、Vite |
| パッケージ管理 | pnpm |
| リンター・フォーマッター | Biome |
| 3D 描画 | Three.js を直接使う（React Three Fiber は使わない） |
| カメラ制御 | camera-controls（yomotsu） |
| 画面 UI | 素の TypeScript（必要になったら軽量なフレームワークを入れる） |
| 音 | Web Audio API |
| 保存 | IndexedDB |
| 単体テスト | Vitest |
| 通しのテスト・見た目の確認 | Playwright |

- 回転の計算（力のつり合い、ロックの検出、位相合わせ、配置の木構造、干渉判定）は、描画から切り離した **純粋な関数** として実装し、単体テストを厚く書く。
- シーンは不変データとして持つ。Undo/Redo、自動保存、エクスポートは同じ形式を使う。
- **テストの方針**
  - Vitest: 上記の純粋な関数を厚くテストする。音の高さや、鳴らす音源の選び方の計算もここで確かめる。
  - Playwright（通し）: 主要な操作の流れを数本。例: シャフトを置く → 歯車を生やす → モーターで回る → 保存して読み込む → Undo。
  - Playwright（見た目）: 決めた場面のスクリーンショットを撮り、人が目で確かめるために保存する。前回との画像比較はしない。自動で判定するのは、画面が真っ黒・真っ白でないこと、コンソールにエラーが出ていないことだけ。
    - 場面の例: 真鍮と木製の各テーマ、かみ合っている歯車の拡大、ロック中の赤い表示、情報表示の ON、日本語と英語の UI。
  - 性能（歯車 200 個で 60fps）は自動テストにせず、手元で計測するスクリプトを用意する。
  - Playwright は Chromium のみ（WebGL は GPU が使えれば GPU、使えなければソフトウェア描画の SwiftShader）。アプリの状態は、開発用とテスト用のビルドに限り公開する `window.__gearSim` から読む。
- **進め方**: 開発は `docs/tasks/` のタスク単位で進める。各タスクで `pnpm verify`（biome check → tsc → vitest → 変えた範囲の playwright）が通ったらコミットする。段階の節目には `pnpm verify:all`（playwright を全部）を流す。

## 13. 開発の段階

1. **基盤**: 平歯車、シャフト、モーター（小・中・大）、力のつり合いの計算、ロック、配置（生やす方式、起点のシャフト、ハンドル）、干渉判定、カメラ、音、テーマ（真鍮・木製）、保存（作品一覧、エクスポートとインポート）、Undo/Redo、情報表示、日本語と英語
2. **軸の向きを変える歯車**: かさ歯車、ウォームギア（セルフロック）、ハスバ歯車、ねじ歯車
3. **同軸・直線の機構**: 固定具、内歯車、遊星歯車（キャリア）、ラック（端で止まる）

## 14. 拡張候補（今回の範囲外）

- 慣性（回り始めと惰性で止まる動き）
- 90° 以外の角度のかさ歯車・ねじ歯車
- 歯数比 1:1 以外のかさ歯車
- チェーン、ベルト
- ラック端のばね付き止め（跳ね返り）
- 音階に合わせて鳴らすモード
- テーマの追加（例: カラフルなプラスチック）
- GIF や動画の書き出し
- タッチ操作への本格対応
