## 4. まとめ

### 4.1 既存製品のカテゴリ

1. **工学・設計ツール**(Gear Generator、woodgears、iGearbox): 歯形が正確でエクスポートでき、比も計算できる。ただし UI は「設計」寄りで、遊びや癒やしの要素はほとんどない。
2. **ステージ型パズル**(Cogs、Gear Combination、Crazy Gears Box、itch.io や Coolmath の各作品): 決まった盤面にスナップで置いて目標を満たす。モバイルでは「ASMR」「relaxing」を売りにしたものが増えている。
3. **本格物理サンドボックス**(Algodoo、GearBlocks、Geareo、Gear X): 自由度は高いが、操作を覚える必要がある。大半はダウンロード型で、詰まりや破綻も起きる。
4. **ピタゴラ装置系**(Contraption Maker、The Incredible Machine): 歯車は多くの部品の一つにすぎない。
5. **小さなブラウザ玩具**(Gear Paint、Aetheric Gears、Gear Fidget Toy、AstroGear): 手軽だが、作り込みや演出、共有機能が弱い。どれも個人の小規模作品。

### 4.2 空白地帯と狙い目(「気持ちいい・癒やし系の歯車配置トイ」をブラウザで出す場合)

- **ブラウザで遊べて、作り込まれた癒やし系の自由サンドボックスが見当たらない。** 癒やし系の作品はモバイルのパズル(Crazy Gears Box など)か、ダウンロード型(Gear X)ばかり。ブラウザにあるのは設計ツールか小さな試作品にとどまる。
- **「自然にスナップするけれど見た目は本物」の中間を突けていない。** Gear Paint は手で位置を合わせるので噛み合わせに失敗しやすく、Algodoo や Gear X は物理演算なので詰まる。インボリュート歯形で描きつつ、近づけると自動で正しい中心距離と位相に吸着させれば、誰でも必ず気持ちよく噛み合う。これは明確な差別化になる。
- **音と触感の演出がほぼ空白。** カチカチ音、歯数や回転数に応じたリズムや音程、回転速度に合わせたアンビエント BGM など。ASMR を打ち出しているのはモバイルパズル(Crazy Gears Box)くらい。歯車列を「楽器」にする方向(噛み合いの周波数を音にするなど)は手つかずに近い。
- **共有・鑑賞の機能。** URL 一つで配置を共有する、ループ GIF や動画で書き出す、壁紙やスクリーンセーバーとして全画面で眺めるモード。Algobox 以外にこうした共有文化はほとんどない。
- **チェーン・ベルト・遊星・内歯車・ラック・同軸の重ね(複合歯車)を、癒やし系 UI のまま扱えるもの。** 設計ツールにはあるが、遊び向けにはない。
- **見た目のテーマ性。** スチームパンク、時計の内部、木工、ガラスなど。Aetheric Gears が雰囲気の需要を示しているが、こちらは鑑賞専用で操作できない。
- **ゆるい目標(任意)。** 歯車比で針を正確な速度に回す「時計をつくる」課題や実績など。純粋なサンドボックスに軽いお題を添えると続けて遊ばれやすい。Gear Combination は目標速度という形が成り立つことを示している。
- **モバイルブラウザ対応とタッチ操作。** 既存のブラウザ作品の多くは PC 前提か、仕上げが甘い。

### 4.3 よく褒められる点と不満点(傾向)

**褒められる点**
- 歯車が噛み合って一斉に回り出す瞬間の気持ちよさ(Create Mod の人気、Gear X や Crazy Gears Box の打ち出し)
- 時間制限なしで片手で遊べる、ASMR 音といった癒やし要素(Crazy Gears Box)
- 大小の歯車で速度や向きが変わるのを直感的に学べる教育効果(Gear Paint、Gear Generator)
- ユーザー作品の共有とワークショップ(Algodoo の Algobox、Contraption Maker の Workshop)
- 壊れない・破綻しないという手加減(Geareo は高トルクでも壊れない設計を評価されている)

**不満点**
- 噛み合わせの位置合わせが難しく、重ねすぎると回らない(Gear Paint の注意書き、物理系全般)
- 物理演算で詰まる、振動する、破綻する(Gear X が「特定の組み合わせで全部詰まる」と明記している)
- 設計ツールは UI が専門的で、遊ぶ目的には向かない(Gear Generator には公式ドキュメントがないという報告もある)
- 本格サンドボックスは学習コストが高く、ダウンロードも要る
- モバイルパズルは広告が多い/レベルの水増し(1000 以上のレベル)になりがち(一般的な傾向。個別のレビューは未確認)

### 4.4 差別化の方向性(提案)

1. **必ず気持ちよく噛み合うマグネット吸着と、本物のインボリュート描画** を組み合わせる
2. **音を主役にする**: 噛み合いのクリック音や回転に合わせた音階を出し、歯車列で音楽をつくれる
3. **一つの URL で共有でき、ループ動画も書き出せる**
4. **眺めるモード**(全画面、UI 非表示、ゆっくりカメラ)
5. **チェーン、ベルト、同軸の複合歯車、内歯車** を少しずつ解放する
6. **ログイン不要、インストール不要、スマホでも快適**
