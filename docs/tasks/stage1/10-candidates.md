# S1-10 生やす候補の列挙

## 目的
要件 §6「歯車を選ぶと、かみ合わせられる場所の候補が表示される。候補には、同じ大きさで干渉しないものだけを出す」の計算部分を純粋関数として作る。完了すると、選んだ歯車について、外周の候補（新しいシャフトを作る）と同じ軸の候補（既存のシャフトに通す）を列挙できる。表示とクリックは S1-18。

## 範囲
- 候補の 2 種類（段階 1）
  - **外周**: 選んだ歯車を親として、その外周にかみ合う新しい歯車と、それを載せる `mesh` のシャフトを作る。新しい歯車の大きさは親と同じ（かみ合えるのは同じ大きさだけ）
  - **同じ軸**: 選んだ歯車のシャフトに、新しい歯車を重ねて載せる。大きさは呼ぶ側が指定する（違う大きさへ動力を受け渡すための候補なので、親と違ってよい）
- 外周の角度の代表のさせ方
  - 角度は連続だが、候補は **親の軸まわりに 45° 刻みの 8 方向**（`angle = k·π/4`、k = 0〜7。角度の基準は S1-03 の `radialDirection`）で代表させる。刻みの数は定数 `PERIMETER_CANDIDATE_COUNT = 8`
  - 候補を置いた後の細かい角度は、S1-19 の円弧ハンドルで連続的に動かす
- 同じ軸の位置
  - 選んだ歯車のシャフトに載った歯車の並びの **両端の外側** に、面を接して置く 2 か所。新しい歯車の `offset` は、負の側が `最小の面 − 新しい歯幅`、正の側が `最大の面`（面 = `offset` と `offset + 歯幅`。`offset` は歯幅の負側の面の位置。design.md §4）
  - 歯幅はすべて `AXIAL_SNAP` の倍数なので、どちらの候補の `offset` も 4 mm の格子に乗る
  - 並びの途中の隙間は候補にしない
- 絞り込み（候補として出す条件）
  - 新しい歯車の歯数がその大きさの範囲に入る（入らなければ呼び出しの誤りとして例外）
  - 候補を足した仮のシーンを `resolveLayout` し、新しい歯車・新しいシャフト・（同じ軸の候補では）伸びたシャフトのいずれかを含む干渉が無い
    - 既にあった干渉（新しい部品を含まない組）は、候補の可否に関係しない
    - 新しい歯車が偶然ちょうどの距離で別の歯車とかみ合う（`contact`）のは許す。位相が合っているかどうかは問わない（contact は干渉にならない。design.md §5）
  - 実装は仮のシーンを毎回作って `resolveLayout` してよい（歯車 200 枚で、1 回の列挙が 50ms 程度に収まれば十分）。速くするなら、結果が同じになることをテストで確かめる
  - 仮のシーンの新しい部品の ID は、既存の ID と重ならない仮の値（例 `'__candidate_gear'`）を使い、戻り値には含めない
- 並び: 外周の候補を角度の昇順、続けて同じ軸の候補を負の側・正の側の順

## 範囲外
- 候補の表示、クリックで生やす、生やす歯車の大きさ・歯数の初期値の決め方（S1-18。初期値の定数 `DEFAULT_TEETH` は S1-17）
- 候補を実際にシーンへ足す編集コマンド（S1-11 の `growGear`。候補の形はこのコマンドの引数にそのまま変換できるようにする）
- 外周の角度の円弧ハンドル、シャフト上の位置のドラッグと吸着（S1-19）
- かさ歯車・ウォームでの 90° の候補（S2-02、S2-03）

## 作るもの
- `src/core/constants.ts` に `PERIMETER_CANDIDATE_COUNT` を design.md §3 の表の値（8）で足す
- `src/core/layout/candidates.ts`
  ```ts
  export interface GrowSpec {
    perimeterTeeth: number; // 外周の新しい歯車の歯数（大きさは親と同じ）
    coaxialSize: SizeKey;   // 同じ軸の新しい歯車の大きさ
    coaxialTeeth: number;   // 同じ軸の新しい歯車の歯数
  }

  export type GrowCandidate =
    | {
        kind: 'perimeter';
        parentGearId: GearId;
        angle: number;   // 親の軸まわり（rad）。k·π/4
        size: SizeKey;   // 親と同じ
        teeth: number;
        center: Vec3;    // 新しい歯車の中心（仮の表示用）
        axis: Axis;
        basePhase: number; // 新しい歯車の位相（仮の表示を正しくかみ合わせて見せる用）
      }
    | {
        kind: 'coaxial';
        shaftId: ShaftId;
        offset: number;  // 歯幅の負側の面の位置。AXIAL_SNAP の倍数
        size: SizeKey;
        teeth: number;
        center: Vec3;
        axis: Axis;
      };

  export function listGrowCandidates(scene: Scene, gearId: GearId, spec: GrowSpec): GrowCandidate[];
  ```
  - `layout` は内部で `resolveLayout(scene)` から得る（キャッシュが効く）

## 受け入れ条件
- [ ] 外周の候補は親と同じ大きさで、正しい中心距離・角度にある
- [ ] 干渉する候補は出ない。既存の干渉は候補を減らさない
- [ ] 同じ入力なら同じ順で返る

## テストケース
大きさは特に書かない限り S（12 歯: ピッチ円半径 6、歯先円半径 7、歯幅 4）。起点 `A` は `axis 'y'`、原点、12 歯 `offset 0`（中心 `[0, 2, 0]`）。軸 `'y'` の角度は `0 → +Z`、`π/2 → +X`。
### Vitest
- [ ] 歯車 1 枚だけ、`perimeterTeeth 12` → 外周の候補 8 個、角度 `0, π/4, …, 7π/4`。`angle 0` の中心 `≈ [0, 2, 12]`、`angle π/2` の中心 `≈ [12, 2, 0]`、全て `size 'S'`、`axis 'y'`。`angle π/2` の `basePhase ≡ π/12`（`2π/12` を法として）
- [ ] `perimeterTeeth 40` → 8 個、中心距離 26
- [ ] 親が M・20 歯、`perimeterTeeth 20` → 8 個、中心距離 40、`size 'M'`
- [ ] 子があるときの絞り込み: `A` に子 `B`（12 歯、`angle π/2`、中心 `[12, 2, 0]`）
  - `A` を選ぶ → 外周の角度は `0, π, 5π/4, 3π/2, 7π/4` の 5 個（`π/4`・`π/2`・`3π/4` は `B` と中心距離 `< 14` で干渉）
  - `B` を選ぶ → 外周の角度は `0, π/4, π/2, 3π/4, π` の 5 個（`A` の側の 3 方向が干渉）
- [ ] 偶然のかみ合いは許す: `A` → `B`（`angle π/2`）→ `C`（`B` の子、`angle 0`、中心 `[12, 2, 12]`）で `C` を選ぶ → `angle 3π/2` の候補（中心 `[0, 2, 12]`、`A` と距離 12。S1-09 の四角形）が出る
- [ ] 位相が合わなくても許す: 歯車 1 枚だけの `A` に、起点 `F`（`axis 'y'`、`origin [24.5, 0, 0]`、13 歯 `offset 0`）を足す → `A` の `angle π/2` の候補（中心 `[12, 2, 0]`）は `F` と中心距離 12.5（ピッチ円半径の和）で、位相は 1/4 ピッチずれるが contact になるので出る。`A` の外周の候補は 8 個のまま
- [ ] 同じ軸: 歯車 1 枚だけ、`coaxialSize 'S'`、`coaxialTeeth 12` → 同じ軸の候補 2 個、`offset −4`（中心 `[0, −2, 0]`）と `offset 4`（中心 `[0, 6, 0]`）
- [ ] 同じ軸・違う大きさ: `coaxialSize 'M'`、`coaxialTeeth 20`（歯幅 8）→ `offset −8`（中心 `[0, −4, 0]`）と `offset 4`（中心 `[0, 8, 0]`）
- [ ] 同じ軸・並びの両端: `A` に 12 歯を `offset 0` と `offset 4` の 2 枚、`offset 0` の方を選ぶ → 同じ軸の候補は `offset −4` と `offset 8`
- [ ] 同じ軸・片側がふさがる: 起点 `E`（`axis 'y'`、`origin [13.5, 4, 0]`、12 歯 `offset 0`。歯車は y が 4〜8）を足す（`A` の歯車（y が 0〜4）とは面が接するだけで干渉なし）→ `A` を選ぶと同じ軸の候補は `offset −4` だけ（`offset 4` は `E` と中心距離 13.5 < 14 で干渉）
- [ ] 既存の干渉は関係しない: 上のシーンに、`A` から十分離れた所で互いに重なった起点 2 本（例 `origin [200, 0, 0]` と `[205, 0, 0]`）を足しても、`A` の候補は変わらない
- [ ] 歯数が範囲外: `perimeterTeeth 81`（S）→ 例外。`coaxialSize 'L'`、`coaxialTeeth 41` → 例外
- [ ] 並び: 外周（角度の昇順）→ 同じ軸（負 → 正）
- [ ] 入力のシーンを変更しない（`Object.freeze` したシーンで呼んでも例外にならない）
- [ ] 性能の目安: 12 歯の歯車 200 枚の木（`resolveLayout` で干渉なしになる配置を生成）で、1 回の列挙が 200ms 未満（テストの上限。目標は 50ms）
