# S1-18 候補の表示とクリックで歯車を生やす

## 目的
要件 §6 の「既存の歯車から生やす」方式を画面で使えるようにする。歯車を選ぶと、かみ合わせられる場所の候補が出て、クリックするだけで正しい位置・向き・位相の歯車が増える。

## 範囲
- 歯車を 1 つ選んでいるとき、S1-10 の候補の列挙の結果を、半透明の仮の歯車（外周の候補では仮のシャフトも）として表示する
  - マウスを乗せた候補は濃く表示する
  - 候補を出さないとき: 選択が無い・シャフトを選んでいる・ハンドルをドラッグ中・手で回している最中
  - 候補は、選択かシーンが変わるたびに列挙し直す
- **生やす歯車の大きさと歯数**（このタスクで決める）
  | 候補 | 大きさ | 歯数 |
  |---|---|---|
  | 外周（新しいシャフトを作る） | 親と同じ（同じ大きさ同士しかかみ合わないため） | `DEFAULT_TEETH[大きさ]`（S1-17） |
  | 同じ軸（親のシャフトに通す） | パレットで選んでいる大きさ（S1-17） | `DEFAULT_TEETH[大きさ]` |
  - 歯数は生やした後にプロパティパネル（S1-20）で変える。生やす前に歯数を選ぶ UI は作らない
  - S1-10 の列挙関数に、この大きさと歯数を渡す（引数の形は S1-10 に合わせる）。候補の位置や干渉の有無は、生やす歯車の大きさと歯数によって変わるため
- 候補をクリック（`DRAG_THRESHOLD_PX` 未満）すると、S1-11 の `growGear` で歯車を足す
  - 外周の候補: 新しい `mesh` のシャフト（`parentGearId` = 選んでいた歯車、`childGearId` = 新しい歯車、`angle` = 候補の角度）と歯車ができる
  - 同じ軸の候補: 選んでいた歯車のシャフトに、候補の `offset` で新しい歯車を通す
  - Undo 1 回で消える
  - 生やした歯車を選択する（続けて次の候補が出るので、つなげていける）
- 候補の上の左ドラッグはカメラの回転にする（候補は手で回せないため）。S1-13 の振り分けで、候補は「左クリックだけアプリが受け取る」扱いにする
- 生やした歯車は、親が回っていればすぐに一緒に回る（運動の状態はシーンから毎回求まる）

## 範囲外
- 候補の列挙そのもの（S1-10）
- 外周の角度を生やした後に動かす、シャフト上の位置を動かす（S1-19）
- 歯数の変更（S1-20）
- かさ歯車・ウォームでの 90° の候補（段階 2: S2-02、S2-03）

## 作るもの
- `src/app/grow.ts`（純粋関数）
  ```ts
  export type CandidateKind = 'mesh' | 'coaxial';
  export function growSpec(
    parent: Gear,
    kind: CandidateKind,
    paletteSize: SizeKey,
  ): { size: SizeKey; teeth: number };
  ```
- `src/render/candidates.ts`: 候補の仮の歯車の表示（形状データは S1-02 の共有のものを使い、材質だけ半透明にする）。ピッキングの種類は `'candidate'`
- S1-13 の振り分け（`routePointerDown`）に、候補のための区別を足す（例: `overInteractive` を `'none' | 'app' | 'click-only'` にする）。S1-13 の Vitest も合わせて直す
- `__gearSim` に追加（design.md §10 も更新する）
  ```ts
  // 今表示している候補。center は仮の歯車の中心のワールド座標
  getCandidates(): Array<{ index: number; kind: CandidateKind; center: Vec3 }>;
  ```
- `e2e/fixtures/one-root.json`: 縦軸の起点のシャフト（原点 `[0, 35, 0]`）に中・20 歯の歯車 A を 1 枚
- `e2e/fixtures/one-root-motor.json`: 上に加えて、A のシャフトに中のモーター（30 rpm、正の向き、ON）

## 受け入れ条件
- [ ] 歯車を選ぶと候補が出て、選択を外すと消える
- [ ] 外周の候補をクリックすると、新しいシャフトと歯車が親にかみ合う位置に置かれる
- [ ] 同じ軸の候補をクリックすると、親のシャフトに、パレットで選んだ大きさの歯車が通る
- [ ] 生やした歯車が選ばれ、そのまま次を生やせる
- [ ] 生やした直後に干渉は無い。Undo 1 回で消える

## テストケース
### Vitest
- [ ] `growSpec`: 親が中・25 歯で `'mesh'`、パレットが大 → `{ size: 'M', teeth: 20 }`
- [ ] `growSpec`: 親が中・25 歯で `'coaxial'`、パレットが大 → `{ size: 'L', teeth: 16 }`
- [ ] `growSpec`: 親が小で `'mesh'` → `{ size: 'S', teeth: 30 }`
### Playwright（`e2e/grow.spec.ts`）
準備: `one-root.json` を読み込み、斜め上から見下ろす視点にする。候補の位置は `getCandidates()` の `center` を `projectToScreen` して得る。
- [ ] 何も選んでいない → `getCandidates()` が空
- [ ] A をクリック → `'mesh'` と `'coaxial'` の候補がそれぞれ 1 つ以上ある
- [ ] `'mesh'` の候補をクリック → 歯車が 2 枚、シャフトが 2 本。新しいシャフトは `placement.kind: 'mesh'`、`parentGearId: A`、`childGearId` が新しい歯車。新しい歯車は `size: 'M'`、`teeth: 20`。`getLayout().meshes` に A と新しい歯車の組（`source: 'tree'`）がある。2 つの中心の距離が 40（ピッチ円半径の和）。`getLayout().interferences` が空。`getSelection()` が新しい歯車で、`getCandidates()` は新しい歯車の候補になっている
- [ ] Ctrl+Z → 歯車 1 枚、シャフト 1 本に戻る
- [ ] パレットで「大」を選び、A を選んで `'coaxial'` の候補をクリック → A のシャフトに `size: 'L'`、`teeth: 16` の歯車が増え、シャフトは増えない。`offset` が −12 か 8（A の面に接する両側。design.md §4 の `offset` の定義で、どちらも `AXIAL_SNAP` の倍数）
- [ ] 外周の候補を 3 回続けてクリックしていく（毎回、新しく選ばれた歯車の候補から 1 つ）→ 4 枚の鎖になり、`interferences` が空
- [ ] 候補の上で左ドラッグ → 歯車は増えず、`getCamera()` が変わる
- [ ] `one-root-motor.json` で外周に 1 つ生やす → 新しいシャフトの `getMotion().omegas` が、A のシャフトの ω（π rad/s）の −1 倍（`toBeCloseTo`）
### Playwright（見た目）
- [ ] 候補が出ている場面のスクリーンショットを `screenshots/candidates.png` に保存する。真っ黒・真っ白でないこと

## 人が手で確かめる項目
- 候補が実物の歯車と見分けられ、かつ置いた後の様子が想像できる見た目である
- 候補が多いときも、狙った候補をクリックしやすい
- 生やした歯車の位相が親と合っていて、歯がめり込んで見えない
