# S1-08 干渉判定

## 目的
要件 §6「重なる配置は置けない。編集の連鎖で重なった場合は赤く警告する。判定は歯車を円柱、シャフトを線分で近似した簡易計算で行う」の計算部分を純粋関数として作る。完了すると、部品の形（円柱・線分）の一覧から、干渉している組を列挙できる。S1-09（`Layout.interferences`）と S1-10（候補の絞り込み）がこれを使う。

## 範囲
- 部品の近似（コライダー）
  - 歯車 = 円柱。中心、軸（`'x' | 'y' | 'z'`）、半径 = 歯先円半径（`outsideRadius`）、半分の厚み = 歯幅 / 2
  - シャフト = 線分。両端の点（太さ 0）
  - モーターは判定しない（段階 1。形と位置が決まったら足す）
- 干渉の判定（触れているだけは干渉としない。重なりの深さが `COLLISION_EPS` 以下なら干渉なし）
  - 円柱 × 円柱（軸が平行）: 軸方向の区間の重なりが `COLLISION_EPS` より大きく、かつ軸に垂直な方向の中心間の距離が `半径の和 − COLLISION_EPS` より小さい
  - 円柱 × 円柱（軸が直交）: 正確に判定する。方法は任せる（例: 軸 a の円柱 P と軸 b の円柱 Q、残りの軸を c として、`d_a` = Q の中心の a 座標から P の a 方向の区間までの距離、`d_b` = P の中心の b 座標から Q の b 方向の区間までの距離とすると、`r_Q² > d_a²` かつ `r_P² > d_b²` かつ `|P_c − Q_c| < √(r_Q² − d_a²) + √(r_P² − d_b²)` のとき重なる。しきい値は `COLLISION_EPS` で調整する）
  - 線分 × 円柱: 線分の一部が円柱の内側（境界から `COLLISION_EPS` より深く）に入る
  - 線分 × 線分: 同じ直線の上にあって重なりの長さが `COLLISION_EPS` より大きい、または、平行でなく、両方の内側の点（端点から `COLLISION_EPS` より離れた点）で交わる（距離が `COLLISION_EPS` 未満）
- 除外する組（干渉としない）
  - 歯車と、それが載っているシャフト
  - 呼ぶ側が渡す「かみ合っている組」（`Layout.meshes` の組。歯先円どうしは重なるが干渉ではない）
- 結果の形: 組の中の 2 つの ID を辞書順に並べ（`[小さい ID, 大きい ID]`）、組の一覧も辞書順に並べる。重複なし
- app への組み込み: このタスクで、S1-04 の暫定の `resolveLayout` の `interferences` を `findInterferences` で埋める（全ての歯車の円柱と、全てのシャフトの線分 `origin + span × 軸`。`exempt` は `meshes` の組）。S1-09 が完全版に置き換える
- 性能: 部品 400 個程度（歯車 200 枚 + シャフト 200 本）で、総当たりでも 1 回 20ms 以内を目安にする（Vitest で測って極端に遅くないことだけ確かめる。超えるなら軸ごとの区間での粗い絞り込みを入れる）

## 範囲外
- 偶然のかみ合い（contact）を含めた完全な `Layout.interferences`（S1-09）
- 候補の絞り込み（S1-10）
- 赤い警告の表示（S1-22）
- 段階 2・3 の部品（かさ歯車の円錐、ウォーム、ラックの箱など。それぞれのタスクで形を足す）

## 作るもの
- `src/core/constants.ts` に `COLLISION_EPS` を design.md §3 の表の値（1e-6 mm）で足す
- `src/core/layout/collision.ts`
  ```ts
  export type Collider =
    | { kind: 'cylinder'; id: GearId; shaftId: ShaftId; center: Vec3; axis: Axis; radius: number; halfWidth: number }
    | { kind: 'segment'; id: ShaftId; start: Vec3; end: Vec3 };

  export function gearCollider(id: GearId, shaftId: ShaftId, center: Vec3, axis: Axis, size: SizeKey, teeth: number): Collider;

  export function collides(a: Collider, b: Collider): boolean;

  // 全ての組を調べる。exempt の組（順序は問わない）と、歯車とそれが載ったシャフトの組は除く
  export function findInterferences(
    colliders: readonly Collider[],
    exempt: ReadonlyArray<readonly [string, string]>,
  ): Array<[string, string]>;
  ```

## 受け入れ条件
- [ ] 触れているだけの配置（歯幅の面どうし、歯先円どうしがちょうど接する）は干渉にならない
- [ ] かみ合っている組を `exempt` に渡せば干渉にならない
- [ ] 結果が決定的な順で返る

## テストケース
円柱は特に書かない限り `radius 7`、`halfWidth 2`（S・12 歯）。
### Vitest
- [ ] `gearCollider('g', 's', [0, 0, 0], 'y', 'S', 12)` → `radius 7`、`halfWidth 2`。`'L', 16` → `radius 27`、`halfWidth 6`
- [ ] 平行: P `y` 軸・中心 `[0, 0, 0]`、Q `y` 軸・中心 `[13, 0, 0]` → 干渉。Q `[14, 0, 0]` → なし（歯先円が接するだけ）
- [ ] 平行・軸方向: Q `[13, 4, 0]` → なし（面が接するだけ）。Q `[13, 3.9, 0]` → 干渉
- [ ] 同軸（同じシャフトに重ねた 2 枚）: P `[0, 0, 0]`、Q `[0, 3, 0]` → 干渉。Q `[0, 4, 0]` → なし
- [ ] かみ合いの除外: P `[0, 0, 0]`、Q `[12, 0, 0]`（中心距離 = ピッチ円半径の和）→ `exempt` なしでは干渉、`exempt = [[P, Q]]` では干渉なし。`exempt = [[Q, P]]`（逆順）でも同じ
- [ ] 直交: P `y` 軸・中心 `[0, 0, 0]`、Q `x` 軸・中心 `[0, 9, 0]` → なし（接するだけ）。Q `[0, 8.9, 0]` → 干渉
- [ ] 直交・斜めの位置: Q `x` 軸・中心 `[0, 5, 10]` → 干渉（例えば点 `(0, 1.9, 5)` が両方に入る）。Q `[0, 5, 14]` → なし
- [ ] 線分 × 円柱: 線分 `[−20, 0, 0]`〜`[20, 0, 0]` と P（`y` 軸・原点）→ 干渉（貫通）。線分 `[8, 0, 0]`〜`[20, 0, 0]` → なし。線分 `[5, −10, 0]`〜`[5, 10, 0]`（軸と平行で内側）→ 干渉。`[7.5, −10, 0]`〜`[7.5, 10, 0]` → なし。`[0, 2, −20]`〜`[0, 2, 20]`（上の面に接する）→ なし
- [ ] 歯車と自分のシャフト: P（`shaftId: 's1'`）と線分 `s1`（`[0, −10, 0]`〜`[0, 10, 0]`）→ 干渉なし。同じ線分の ID が `s2` → 干渉
- [ ] 線分 × 線分: `[0,0,0]`〜`[10,0,0]` と `[5,0,0]`〜`[15,0,0]` → 干渉。`[10,0,0]`〜`[20,0,0]` → なし（端で接するだけ）。`[−10,0,0]`〜`[10,0,0]` と `[0,0,−10]`〜`[0,0,10]` → 干渉（中で交差）。後者を y = 0.1 にずらす → なし。`[0,0,0]`〜`[0,0,10]`（端点が前者の内側に触れるだけ）→ なし
- [ ] `findInterferences` の並び: ID `g2`・`g1`・`g3` の 3 つが互いに重なる → `[['g1','g2'], ['g1','g3'], ['g2','g3']]`
- [ ] 性能の目安: 中心を 30mm 間隔の格子に並べた円柱 200 個と線分 200 本（干渉なし）→ 干渉 0 件、実行時間が極端でない（1 回 100ms 未満を上限としてテストする）
