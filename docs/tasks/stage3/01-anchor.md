# S3-01 固定具（アンカー）

## 目的
シャフトを地面に固定して回らなくする固定具を入れる。遊星歯車機構（S3-03）のように自由度が 2 ある機構を、どこか 1 つを止めて使えるようにするための部品。固定具と矛盾する駆動はロックとして見せる。

## 範囲
- **データ**: シーンに `anchors` を足す
  - 固定する対象はシャフト（このタスク）。歯車を固定するときは、その歯車のシャフトを固定する（剛体の単位がシャフトのため。§6）
  - 1 つの対象に固定具は最大 1 つ
  - S3-03 のキャリアはシャフトに載るので、キャリアの固定はそのシャフトの固定になる。S3-04 で対象にラックを足す
- **運動学**（§6 の拡張）
  - 固定されたシャフトに拘束 `ω = 0` を足す（拘束行列 C の行を 1 つ足す）
  - 固定具があっても、駆動されていなければロックではない（止まっているだけ）
  - **ロック**（理由 `'anchor'`）: 段階 1 のロックの条件（零空間が 0 次元なのにモーターがある／|ω| < `LOCK_OMEGA_EPS` でトルクを出すモーターがある）に当たり、かつ、その連結成分から固定具の拘束を外して解き直すとロックしない場合。外してもロックするなら段階 1 の理由のまま
  - **ウォームを含む成分**（S2-03）: ウォームのかみ合いを含む連結成分は、段階 1 のつり合いの代わりに `src/core/kinematics/worm-solve.ts`（区画に分けてトポロジカル順に解く）で解いている。固定具の拘束 `ω = 0` は、固定したシャフトを含む区画の拘束の行として足す（区画の中の拘束なので、その区画の零空間に入る）。`'anchor'` の判定（固定具を外して解き直す）も、この解き方で行う
  - **手で回す**: つかんだシャフトが固定具によって動けない（固定具の拘束を入れた零空間で、そのシャフトの成分がすべて 0）なら、ドラッグ中はロック（理由 `'anchor'`）。動ける自由度が残っていればそちらが動く
- **編集**（`core/edit`、Undo の対象）
  - 固定する・固定を外すコマンド
  - シャフトを消すと、そのシャフトの固定具も消える（1 つのコマンド、Undo で両方戻る）
  - 歯車を消しても、シャフトが残る限り固定具は残る
- **UI**
  - プロパティパネル: シャフトか歯車を選んでいるとき「固定する」のチェック（歯車のときはそのシャフトを固定する旨を表示）
  - コンテキストメニュー（S1-29）: シャフト・歯車の上で「固定する」／「固定を外す」
  - 国際化のキー（日・英）
- **表示**
  - 固定されたシャフトの負の端に、留め具の形（四角い台座）を描く。シャフトが床より上にあるときは、台座から床まで細い支柱を下ろす（見た目だけ。重力はない）
  - 固定具は干渉判定に含めない（見た目のための部品で、配置の邪魔をしない）
  - 固定具と矛盾してロックしたときは、段階 1 のロックの表示（赤く震える）をそのまま使う
- **保存（暫定）**: 読み込みで `anchors` がないシーンは `{}` を補う（S1-28 の `parseScene` で補い、形を確かめる。`parseScene` は型にないフィールドを捨てるので、`anchors` を拾わないと読み込みで消える）。保存形式の version 3 への移行は S3-05 で書き、この暫定処理はそこで移行に置き換える

## 範囲外
- ラックの固定（S3-04）
- 固定具専用の材質・音（S3-05。ロックの音は段階 1 のものが鳴る）
- 保存形式の version 3（S3-05）
- 固定具をシャフトの任意の位置に動かすこと（範囲外。常に負の端）

## 作るもの
- `src/core/scene/`
  ```ts
  type AnchorId = string; // "anchor_xxx"
  interface Anchor {
    readonly id: AnchorId;
    readonly target: { readonly kind: 'shaft'; readonly id: ShaftId }; // S3-04 で { kind: 'rack'; id: RackId } を足す
  }
  interface Scene {
    // 既存のフィールドに加えて
    readonly anchors: Readonly<Record<AnchorId, Anchor>>;
  }
  ```
- `src/core/kinematics/`: 固定具の拘束、ロックの理由 `'anchor'` の判定
  ```ts
  type LockReason = /* 既存の理由 */ | 'anchor';
  ```
- `src/core/edit/`: `addAnchor(targetShaftId)`、`removeAnchor(anchorId)`（コマンドの形は段階 1 に合わせる）。シャフト削除のコマンドで固定具も消す
- `src/render/`: 固定具の描画
- `src/ui/`: プロパティパネルのチェック、コンテキストメニューの項目
- `e2e/fixtures/anchor-pair.json`: 縦軸の起点のシャフト（原点 `[0, 35, 0]`）に中・20 歯 A とモーター 中（30 rpm、正の向き、ON）。A の外周に中・40 歯 B。固定具はなし
- **design.md の書き換え**
  - §4: `Scene` に `anchors`、`Anchor` 型を足す。「段階 3 で anchors などを足すときは…」の一文を、S3-05 で version 3 に移行することに書き換える
  - §6: 拘束に「固定されたシャフトは ω = 0」を足す。ロックの条件の「固定具との矛盾」を、上の判定方法で具体的に書く。`LockInfo` の理由に `'anchor'`

## 受け入れ条件
- [ ] シャフトか歯車を選んで固定でき、外せる。Undo/Redo できる
- [ ] 固定したシャフトに台座と支柱が描かれる
- [ ] モーターで回っている歯車群のどこかを固定すると、全体が止まり赤く震える。固定を外すと回り出す
- [ ] 駆動されていない歯車を固定しても、ロックにならない

## テストケース
### Vitest
- [ ] `anchor-pair` で B のシャフトを固定 → 両方の ω = 0、ロック 1 件（理由 `'anchor'`）
- [ ] `anchor-pair` で A のシャフト（モーターのあるシャフト）を固定 → ロック（理由 `'anchor'`）
- [ ] `anchor-pair` のモーターを OFF にして B を固定 → ロックなし、ω = 0
- [ ] 段階 1 の理由が残る: 三角形にかみ合う 3 枚（モーター付き）の 1 枚を固定 → ロックの理由は段階 1 の矛盾のまま（固定具を外してもロックするため）
- [ ] 別の連結成分: B を固定し、別の場所に独立したモーター付きの歯車 → そちらは回り続ける
- [ ] 手で回す: B を固定して A をつかむ → ロック（`'anchor'`）。固定のない成分をつかむ → 段階 1 と同じく追従
- [ ] 編集: 固定 → Undo で `anchors` が空 → Redo で戻る。同じシャフトに 2 回固定しようとすると 2 つ目は何もしない
- [ ] 編集: 固定したシャフトを削除 → `anchors` が空。Undo でシャフトと固定具が両方戻る
- [ ] 読み込み（暫定）: `anchors` のないシーン → `anchors: {}` を補って読める
- [ ] `resolveLayout` の `interferences` は、固定具の有無で変わらない
### Playwright
- [ ] `anchor-pair.json` を読む → B を右クリック →「固定する」→ `getScene().anchors` が 1 件、`getMotion().locks` に `'anchor'`、全 ω が 0
- [ ] 同じ B を右クリック →「固定を外す」→ `locks` が空、A のシャフトの ω が π
- [ ] A を選んでプロパティパネルの「固定する」をチェック → A のシャフトが固定される。Ctrl+Z で外れる
### Playwright（見た目）
- [ ] B を固定してロックしている場面 → `screenshots/anchor-locked.png`

## 人が手で確かめる項目
- 台座と支柱が、固定されていることが一目で分かり、歯車の鑑賞の邪魔にならない
- 横向き・縦向きのどちらのシャフトでも、台座の付き方が自然に見える
