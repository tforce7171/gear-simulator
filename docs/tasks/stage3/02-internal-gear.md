# S3-02 内歯車

## 目的
内側に歯のある内歯車を入れる。外歯車を内側でかみ合わせると、同じ向きに回る。遊星歯車機構（S3-03）のリングとして使う部品でもある。

## 範囲
- **決めた値**（`src/core/constants.ts`）
  - 内歯車の歯数の範囲: `INTERNAL_MIN_TEETH = 24` 〜 大きさごとの最大（小 80、中 60、大 40）
  - かみ合う外歯車との歯数差: `INTERNAL_MIN_TOOTH_DIFF = 12` 以上（内側での歯先の干渉を避けるため。満たさない組はかみ合わない）
  - ピッチ円半径 `R = m·z/2`。歯先（内側）の半径 `R − m`、歯底（外側）の半径 `R + 1.25m`、リムの外側の半径 `R + 3.25m`
  - 歯幅は大きさの歯幅（要件 §3.2）
- **種類** `'internal'`。かみ合えるのは同じ大きさの平歯車だけ（ハスバの内歯車は範囲外）。内歯車同士はかみ合わない
- **ウェブ**: リングは、自分のシャフトとカップ形でつながる。リングの片側の面から軸方向に `INTERNAL_WEB_GAP` 離れた位置に円板（ウェブ）があり、リングとウェブは外周の薄い筒でつながる
  - どちら側にウェブがあるかは `webSide: 1 | -1`（軸の正・負）。既定は −1
  - `INTERNAL_WEB_GAP` は、段階 1 のシャフトの端の余白より大きくする（内側に生やした歯車のシャフトの端がウェブに当たらないように）。値は段階 1 の余白を見て決め、constants.ts に置く
  - リングの反対側は開いていて、外から見て中の歯車が見える
  - 軸方向の位置: `offset` は歯のあるリング（歯幅の区画）の負側の面で、AXIAL_SNAP の倍数（design.md §4）。ウェブとつなぎの筒は区画の外に出る。自分のシャフトの長さ（S1-09）は、区画とウェブの両方を含めて求める。`mesh` の子として置くときも、`offset` 0 でリングの面を相手の歯車の面にそろえる
- **配置**: 段階 1 の `mesh` の配置をそのまま使う。中心距離を、組の種類で決める
  - 外歯車同士: `r_a + r_b`。内歯車と外歯車: `R − r`
  - 内歯車が親: 子の外歯車は内側の、角度 `angle` の方向に `R − r` 離れた位置
  - 外歯車が親: 子の内歯車の中心が、親の中心から角度 `angle` の方向に `R − r` 離れた位置（親を囲む）
- **候補**
  - 内歯車を選ぶと、内側の外周の候補を出す（角度の取り方は段階 1 の外周の候補と同じ）。子は同じ大きさの平歯車で、歯数は S1-18 の既定値を、歯数差の条件を満たすように下げたもの（12 未満になるなら候補を出さない）
  - 平歯車を選ぶと「囲む内歯車」の候補を出す。歯数は `2 × 親の歯数` を、`max(24, 親の歯数 + 12)` 以上・大きさの最大以下に収めたもの（収まらなければ出さない）
  - 同じ軸の候補で `'internal'` を作れるようにする（パレットの種類に足す）
- **偶然のかみ合い（contact）**: 内歯車と平歯車（同じ大きさ）、軸が平行、歯幅が重なり、中心距離が `R − r` と `MESH_DISTANCE_EPS` 以内、歯数差が 12 以上
- **位相**: 接点で、外歯車の歯の中心と内歯車の歯溝の中心が重なるように子の `basePhase` を決める
- **運動学**: 内歯車と外歯車の拘束は `z_ext·ω_ext − z_int·ω_int = 0`（同じ向きに回る）。S2-02 の係数の関数（`src/core/kinematics/mesh-coefficients.ts` の `meshCoefficients`）に足す
- **干渉判定**（S1-08 の拡張）
  - 内歯車は **中空の円柱**（内側の半径 `R − m`、外側の半径 `R + 3.25m`、軸方向は歯幅）と、ウェブ（円板）・つなぎの筒で近似する。内側は空洞として扱う
  - 平行な歯車（円柱）: 内歯車の軸からの距離 d、歯先円の半径 ρ として、`d + ρ ≤ R − m` なら内側に収まって干渉なし。`d − ρ ≥ R + 3.25m` なら外側で干渉なし。それ以外で軸方向が重なれば干渉
  - 平行なシャフト（線分）: 内側の空洞を通るものは干渉なし。ウェブを貫くものは干渉（自分のシャフトは除く）
  - 平行でない部品: 空洞を無視して外側の円柱として扱う（安全側に倒す）
  - かみ合っている組は、段階 1 と同じく除く
- **形状**: 外歯車の歯形と同じインボリュートを使い、歯と歯溝を入れ替えた内歯（歯は内向き）。リム、つなぎの筒、ウェブ、中心のボスを付ける。形状データのキーは `(種類, 大きさ, 歯数)`（`webSide` は向きの反転で表す）
- **歯数の範囲を種類で決める**: 歯数の範囲を返す関数を作り、プロパティパネルの歯数の入力（S1-20）もそれを使う。編集で木の親子の歯数差が 12 未満になる変更は、コマンドが拒否する（シーンは変わらない）
- **表示**: 段階 1 と同じ材質（材質の違いは S3-05）
- **保存**: シーンの検証で `'internal'` と `webSide` を受け付ける（`version` は 2 のまま。上げるのは S3-05）
- **S2-01 の時点**: 歯車の種類を足すと、`switch (gear.kind)` の `assertNever` でコンパイルエラーになる所（`src/core/scene/gear-shape.ts` の `gearShape`・`newGearShape`・`meshPartnerShape`・`GEAR_KINDS`、`geometry/can-mesh.ts` の `canMesh`・`meshKindOf`、`geometry/shape-key.ts` の `gearShapeKey`、`scene/parse.ts`、`render/gear-geometry.ts` の `buildGeometry`）を直す（design.md §4）。`MeshKind` は `geometry/can-mesh.ts` にある。候補（`GrowCandidate`）は作る歯車の形 `shape: GearShape` を持ち、同じ軸の種類は `GrowSpec.coaxialKind`（app は今 `'spur'` を渡す。`src/app/interactions.ts`）、編集コマンドの種類は `addRootShaft` の `gear.kind?`・`growGear`（coaxial）の `kind?` で渡す。外周に生やす子の形は `meshPartnerShape` で決まる
- **S2-01 の canMesh**: `canMesh(a: Gear, b: Gear)` は種類・大きさ・形を変える属性だけで判定している。歯数の差の条件はここに足す


  ```ts
  export function centerDistance(a: Gear, b: Gear): number; // 平行軸でかみ合う組の中心距離
  ```

- **design.md の書き換え**
  - §3: `INTERNAL_MIN_TEETH`、`INTERNAL_MIN_TOOTH_DIFF`、`INTERNAL_WEB_GAP` を足す
  - §4: `InternalGear` を足す。`mesh` の配置の中心距離が組の種類で決まることを書く
  - §5: contact の条件に内歯車の場合を足す。`MeshKind` に `'internal'`。干渉判定に中空の円柱の扱い
  - §6: 拘束の係数の表に内歯車（`z_ext, −z_int`）を足す

## テストケース
### Vitest
- [ ] `centerDistance`: 中・20 歯の平歯車と中・60 歯の内歯車 → 40。中・20 歯同士の平歯車 → 40
- [ ] `canMesh`: 内 32 歯と平 20 歯 → 真。内 30 歯と平 20 歯（差 10）→ 偽。内歯車同士 → 偽。大きさ違い → 偽
- [ ] `teethRange('internal', 'L')` → `{ min: 24, max: 40 }`。`teethRange('spur', 'S')` → `{ min: 12, max: 80 }`
- [ ] `resolveLayout(internal-pair)`: 中心距離 40、`meshes` に `kind: 'internal'`、`interferences` が空
- [ ] 運動: `internal-pair`（P 2π rad/s）→ G は `2π/3` rad/s（同じ符号）
- [ ] 運動: 内歯車 G にモーターを移す（20 rpm）→ P は 60 rpm（同じ符号）
- [ ] 位相: 接点で P の歯の位置（ピッチを 1 とした端数）が 0 のとき、G の歯溝の中心が重なる（内歯車の歯の位置の端数が 0.5）
- [ ] 内側の候補: 中・30 歯の内歯車から列挙 → 子の歯数は 18（S1-18 の既定 20 を 30 − 12 に下げる）。中・24 歯の内歯車 → 12。小・24 歯の内歯車から（既定 30）→ 12
- [ ] 囲む候補: 中・20 歯の平歯車 → 40 歯の内歯車。大・20 歯 → 40 歯（40 = 最大）。大・30 歯 → 候補なし（42 以上が要る）
- [ ] 干渉: G の内側、G の軸から見て P と反対の方向に距離 10 の位置へ中・12 歯（歯先円の半径 14）の歯車を置く → `10 + 14 ≤ 58` で干渉なし。同じ方向で距離 46 → 内歯車と干渉あり
- [ ] 干渉: G の内側の空洞を通る、G と平行なシャフト → 干渉なし。そのシャフトがウェブまで伸びる → 干渉あり
- [ ] 干渉: G と直交するシャフトが空洞の中を横切る → 外側の円柱として扱うので干渉あり
- [ ] 編集: `internal-pair` で P を 50 歯に → 歯数差 10 で拒否され、シーンが変わらない
- [ ] contact: 木の親子でない平歯車を、G の内側でちょうど `R − r` の距離に置く → contact のかみ合い。P とその歯車の 3 枚が矛盾しなければロックしない
