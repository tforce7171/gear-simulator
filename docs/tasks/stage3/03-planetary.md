# S3-03 遊星歯車とキャリア

## 目的
太陽歯車・遊星歯車・リング（内歯車）・キャリアからなる遊星歯車機構を入れる。遊星が自転しながら公転する様子を眺められ、どこを固定具（S3-01）で止めるかで減速比や向きが変わる。自由度 2 の機構を、段階 1 と同じ一次方程式の仕組み（解が一意でないときは ω の二乗和が最小の解。design.md §6）で解く。

## 範囲
- **部品の構成**
  - 太陽歯車: 普通の平歯車（シャフトの配置は何でもよい）
  - キャリア: 新しい部品。太陽歯車と **同じ線上の別のシャフト** に載り、そのシャフトと一緒に回る剛体。遊星のシャフトを支える
  - 遊星歯車: キャリアに載ったシャフト（遊星のシャフト）上の平歯車。キャリアと一緒に公転し、自分のシャフトで自転する
  - リング: S3-02 の内歯車。太陽歯車と同じ線上の別のシャフトに載る
- **新しい配置** `ShaftPlacement`
  ```ts
  // 親のシャフトと同じ線上の別のシャフト。原点・軸は親と同じ。キャリアやリングのシャフトに使う
  | { readonly kind: 'concentric'; readonly parentShaftId: ShaftId }
  // キャリアに載った遊星のシャフト
  | {
      readonly kind: 'planet';
      readonly carrierId: CarrierId;
      readonly parentGearId: GearId; // かみ合う相手。キャリアのシャフトと同じ線上の歯車（太陽歯車かリング）
      readonly childGearId: GearId;  // このシャフト上の、親とかみ合う歯車
      readonly angle: number;        // キャリアの角度が 0 のときの、キャリアの軸まわりの角度（rad）
    }
  ```
  - どちらも `axis` は持たない（design.md §4）。`concentric` は親のシャフトの軸、`planet` はキャリアのシャフトの軸を導いて `Layout.shafts[id].axis` に出す
  - `planet` の位置の求め方は `mesh` と同じ（中心距離は S3-02 の `centerDistance`。子の `offset` を 0 としてシャフトの原点を決める）。ただしキャリアのシャフトの回転角 θ_c だけ、キャリアの軸まわりに回した位置が実際の位置になる
- **データ**: シーンに `carriers` を足す（下の型）。遊星の数はキャリアを参照する遊星のシャフトの数で、別に持たない
- **Layout と MotionState の関係**（design.md §5 の書き換え）
  - `resolveLayout` はシーンだけから求める純粋関数のまま。遊星のシャフトの位置は **基準配置**（すべてのキャリアの角度が 0）で返し、公転の情報 `orbit` を添える
  - 実際の位置は、core の純粋関数で `Layout` と `MotionState` から求める（キャリアのシャフトの角度だけ回す）。描画、音源の位置、ピッキング、`projectToScreen` はこの関数を使う
  - contact と干渉の判定は基準配置で行う。太陽歯車・リングはキャリアと同軸なので、公転しても遊星との距離は変わらない
  - `MotionState` の形は変えない（キャリアの ω はそのシャフトの ω）
- **運動学**（design.md §6 の書き換え）
  - **ウィリスの式**: 遊星のシャフト上の歯車がかかわるかみ合いでは、両方の ω からキャリアの ω_c を引いた相対値で拘束を書く。太陽 s・遊星 p・リング r では
    ```
    z_s·(ω_s − ω_c) + z_p·(ω_p − ω_c) = 0
    z_p·(ω_p − ω_c) − z_r·(ω_r − ω_c) = 0
    ```
    ω_p は遊星のシャフトの、ワールドに対する自転の角速度。拘束は ω について一次のままなので、零空間と角度の積分（§6）はそのまま使える
  - **決まらない自由度**: design.md §6 は段階 1 から「解が一意でないときは ω の二乗和が最小の解」をとる。このタスクでは §6 の方式を書き換えず、そのままで遊星（自由度 2、駆動はモーター 1 つ）が正しく解けることをテストで確かめる。最小にする二乗和には、遊星のシャフトも 1 本ずつ数える。どこからも駆動されていない連結成分は、これまでどおり止まったまま
  - 自由度 2 の機構は、固定具（S3-01）で 1 つ止めると 1 になる
  - S3-01 の作り（design.md §6）: 運動は固定具の拘束を入れたグラフ（`anchoredMeshGraphOf`）で解く。手で回すときは、つかんだシャフトの行がすべて 0（固定具で動けない）なら先に `'anchor'` のロックにし、そうでなければ自由度 1 の手の扱い（自由度 2 以上は今は例外。このタスクで、残りの自由度をつり合いで解く）。情報表示のギア比は固定具を入れたグラフの `speedRatio` を先に使うので、リングを固定すれば太陽とキャリアの比が出る
- **配置の条件**（`src/core/geometry/` の純粋関数）
  - 等配: 遊星を n 個、`angle = 2πk/n` に置く。リングがあるときは `(z_s + z_r) / n` が整数（そうでないと 1 番以降の遊星とリングの位相が合わず、歯が重なって見える。contact は位相を問わないので干渉としては検出されない。候補と編集のコマンドがこの条件を守る）
  - 同心: `z_r = z_s + 2·z_p`
  - 隣どうしの遊星が当たらない: `(z_s + z_p)·sin(π/n) > z_p + 2`
  - n の範囲は 1〜6
- **候補**: 平歯車（遊星のシャフト上でないもの）を選ぶと「遊星歯車機構」の候補を 1 つ出す。クリックで、その歯車を太陽として、次を 1 つのコマンドで作る
  - キャリアのシャフト（`concentric`）とキャリア。キャリアはリングのウェブの反対側（太陽歯車の軸の正の側）に置き、板の負側の面が太陽の歯幅の正側の面から AXIAL_SNAP の倍数だけ離れた位置に来るようにする（離す量はこのタスクで決める。遊星のシャフトの端の余白と、内側の歯車が板に当たらないことを考える）
  - n = 3 の遊星のシャフト（`planet`、`angle` = 0、2π/3、4π/3）と遊星歯車（太陽と同じ大きさ）
  - リングのシャフト（`concentric`）と内歯車（`webSide: -1`。原点が太陽のシャフトと同じなので、`offset` を太陽と同じにすれば同じ面にそろう）
  - リングは遊星と contact でかみ合う（木の親子ではない）。リングの `basePhase` は、0 番の遊星（`angle` が 0 のもの）とかみ合うように決める。等配の条件を満たせば、残りの遊星とも位相が合う
  - 遊星の歯数 z_p は、12 以上で、上の 3 条件とリングの歯数の範囲（S3-02）をすべて満たす最小の値。なければ候補を出さない
- **編集**（`core/edit`）
  - 遊星の数を変えるコマンド: 遊星のシャフトを作り直して等配にする（1 本目の遊星のシャフトの歯車の並びを写す）。条件を満たさない n は拒否する
  - 機構の中の歯数の変更: 太陽か遊星の歯数を変えると `z_r = z_s + 2·z_p` になるようリングの歯数も変える。同じキャリアの遊星は全部同じ歯数にする。条件を満たさない変更、リングの歯数を直接変える変更は拒否する
  - 遊星のシャフトには、モーターと固定具を付けられない（コマンドが拒否し、UI では項目を出さない）
  - 遊星のシャフト上の歯車からは、同じ軸の候補（段付きの遊星）だけを出す。外へ生やす候補（外周・かさ・ウォーム・ねじ・遊星歯車機構）は出さない
  - 削除: キャリアを消すと、遊星のシャフトはその時点の基準配置の位置で `detached` になる。太陽歯車を消したときも、それを親とする遊星のシャフトは `detached` になる（段階 1 の削除と同じ考え方）
- **手で回す**: 遊星の歯車をつかんだときは、キャリアのシャフトをつかんだものとして扱う（公転を手で回す）
- **干渉判定**
  - 同じ線上のシャフト同士（`concentric`）は干渉としない。描画では入れ子の中空軸に見せる（後から作ったほうを一回り太い筒にする）
  - 太陽・遊星・リング・キャリア・同じキャリアの遊星のシャフトの間は、かみ合いと支えの関係にあるので互いに除く（隣どうしの遊星は上の条件で保証する）
  - 公転する部品（遊星の歯車とシャフト）と、それ以外の部品との判定は、公転で掃く範囲（キャリアの軸まわりの中空円柱）で行う
  - 公転する歯車と、キャリアと同軸でない歯車との偶然のかみ合いは扱わない
- **形状と表示**: キャリアは、遊星のシャフトの数だけ腕のある板（半径は公転半径に遊星のシャフトの太さの余白を足したもの）。遊星のシャフトはキャリアの板まで伸びる。キャリアはピッキングで選べ、プロパティパネルで固定できる（S3-01 の仕組みで、キャリアのシャフトを固定する）
- **保存（暫定）**: 読み込みで `carriers` がないシーンは `{}` を補う（version 3 への移行は S3-05）

- **S3-02 の時点**（design.md §4・§5）
  - 中心距離は `centerDistance(a: Gear, b: Gear)`（`src/core/geometry/dimensions.ts`。外歯車同士は `r_a + r_b`、内歯車と外歯車は `R − r`）。外歯車同士の古い式は `geometry/mesh.ts` の `spurCenterDistance(size, z_a, z_b)` に名前を変えた
  - `meshKindOf(a, b)` は 2 つの形を取る（どちらかが内歯車なら `'internal'`）。内歯車の組の位相は `internalMeshPhase`（`src/core/geometry/internal.ts`。内歯車の位相 0 は 0 番目の内向きの歯が +x。接点で歯の位置の端数が `f_内 = f_外 + 1/2`）。リングの `basePhase` を 0 番の遊星に合わせるときは同じ関係を使う
  - 内歯車の自分のシャフトの `span` はウェブ（ボス）だけを通り、中の空洞に入らない（ウェブの外側の面 − `SHAFT_END_MARGIN` 〜 内側の面）。リングのシャフト（`concentric`）も同じ式で、太陽歯車の歯幅の区間とは重ならない（`webSide` −1・太陽と同じ `offset` なら、リングのシャフトは太陽の面の 8〜16 mm 下）
  - 干渉判定で内歯車は中空の円柱（`collision.ts` の `kind: 'hollow'`）とウェブの円柱の 2 つ（どちらも歯車の ID）。太陽のシャフトはリングの軸上を通るので、空洞を通る平行な線分として扱われ、ウェブまで伸びればウェブと干渉する
  - 候補: 内歯車の親の外周の候補は内側の平歯車（歯数は `min(既定, z − 12)`）。平歯車の親を囲む内歯車の候補（`kind: 'enclose'`）は、パレットで内歯車を選んでいるときだけ出る

## テストケース
共通: 中、z_s = 24、z_p = 12、z_r = 48、n = 3（公転半径 36）。速度は rpm で書く（実装では rad/s に直して比べる）。
### Vitest
- [ ] `planetaryConditions(24, 12, 48, 3)` → すべて真。`(20, 12, 44, 3)` → `equalSpacing` が偽。`(12, 30, 72, 4)` → `clearance` が偽（42·sin45° ≈ 29.7 < 32）
- [ ] `defaultPlanetTeeth`: 中・24 歯 → `{ zp: 12, zr: 48 }`。中・20 歯 → `{ zp: 13, zr: 46 }`。大・12 歯 → `{ zp: 12, zr: 36 }`。大・16 歯 → `null`
- [ ] 零空間: 固定具なし → 次元 2。リングを固定 → 1
- [ ] リング固定・太陽 60 → キャリア 20、遊星 −60（自転、ワールドに対して）、リング 0
- [ ] キャリア固定・太陽 60 → リング −30、遊星 −120
- [ ] 太陽固定・リングにモーター 60 → キャリア 40
- [ ] 固定なし・太陽 60 だけ → 二乗和が最小の解: キャリア ≈ 37.190、リング ≈ 25.785、遊星 ≈ −8.430（3 本とも）（`toBeCloseTo(…, 2)`）。N の基底を入れ替えても同じ値。2 つの拘束の式を満たす
  - この参考値は手計算。検算: モーターに負荷がかからないので太陽は 60。拘束から `ω_p = 3ω_c − 120`、`ω_r = 1.5ω_c − 30`。二乗和 `f = ω_c² + 3·ω_p² + ω_r²`（遊星のシャフト 3 本、太陽は 60 で固定）を ω_c で微分して 0 とおくと `60.5·ω_c = 2250` → ω_c = 37.190。テストでは期待値をこの式から計算してもよい
  - 二乗和は rad/s で求めるが、rpm と比例するので最小になる解は同じ
- [ ] 固定具との矛盾: リングとキャリアを両方固定して太陽にモーター → ロック（`'anchor'`）
- [ ] 基準配置: `resolveLayout` の遊星 0 番のシャフトの原点は太陽の中心から距離 36、`orbit.carrierShaftId` がキャリアのシャフト
- [ ] 公転: リング固定・太陽 60 で 1.5 秒積分（dt = 1/60）→ キャリアの角度 π。`shaftWorldOrigin` の遊星 0 番が、基準配置からキャリアの軸まわりに π 回った位置（太陽の中心をはさんで反対側）
- [ ] 位相: リングと 3 つの遊星がすべて contact のかみ合いになり、`interferences` が空。リングの歯の位置（ピッチを 1 とした端数）が、3 つの遊星との接点すべてで遊星の歯と 0.5 ずれる（歯溝に歯が入る）
- [ ] 位相の合わない組: z_s = 20、z_p = 12、z_r = 44 で同じ配置を手で組む（等配の条件を満たさない）→ contact は位相を問わず拘束なので、3 組とも `meshes` に入り、`interferences` には入らない。このような組は候補と編集のコマンドが作らせないことで防ぐ（`planetaryConditions` の `equalSpacing` が偽）
- [ ] 候補: 中・24 歯の太陽から作った機構が上の共通の値になる。Undo 1 回で全部消える
- [ ] 遊星の数: n = 4 に変更 → (24 + 48)/4 = 18 で受け付け、遊星のシャフトが 4 本、角度が π/2 おき。n = 5 → 72/5 が整数でないので拒否
- [ ] 歯数: 遊星を 18 歯に → リングが 60 歯、(24 + 60)/3 = 28 で受け付け。太陽を 25 歯に → (25 + 49)/3 が整数でないので拒否
- [ ] 遊星のシャフトにモーター・固定具を付けるコマンド → 拒否。遊星の歯車からの候補は同じ軸のものだけ
- [ ] 削除: キャリアを消す → 遊星のシャフトが `detached` になり、位置が消す前の基準配置と同じ
- [ ] 干渉: 太陽・キャリア・リングのシャフト（同じ線上）は互いに干渉しない。機構の外、公転半径の範囲にある別の歯車 → 干渉に入る
- [ ] 手で回す: 遊星の歯車をつかむと、キャリアのシャフトが規定値になる
