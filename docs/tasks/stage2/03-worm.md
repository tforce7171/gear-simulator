# S2-03 ウォームギア

## 目的
ねじれた位置の 90° で大きく減速するウォームギア（ウォーム＋ホイール）を入れる。ホイール側からは回せない **セルフロック** を、力のつり合いの計算に組み込む。完了すると、1 段で 1/12〜1/80 の減速ができ、ホイール側から駆動しようとするとロックする。

## 範囲
- **決めた値**（`src/core/constants.ts`）
  - ウォームの条数 `WORM_THREADS = 1`（固定）。ねじれの向きは右ねじ（固定）。ホイールも右ねじれ
  - ウォームのピッチ円直径 = `WORM_DIAMETER_FACTOR · m`、`WORM_DIAMETER_FACTOR = 10`。進み角 γ = `atan(1/10)` ≈ 5.71°
  - ウォームの長さ（歯のある部分）= `WORM_LENGTH_PITCHES · π·m`、`WORM_LENGTH_PITCHES = 5`
  - ウォームの長さは 4 の倍数にならないので、軸方向の位置（`offset`）の計算では、長さを AXIAL_SNAP の倍数に切り上げた **区画の幅** を歯幅の代わりに使う: `ceil(5πm / 4)·4`（小 16、中 32、大 48）。`offset` は区画の負側の面、ねじ山は区画の中央に置く（中心 = `原点 + (offset + 区画の幅/2)·軸`）。シャフトの長さ・同じ軸に並べたときの重なりも区画の幅で求める
  - ウォームの軸方向ピッチ = `π·m`（m はその大きさのモジュール。ホイールの軸直角モジュールと同じ）
  - ホイールの歯数の範囲と歯幅は、平歯車と同じ（要件 §3.2）。ホイールのピッチ円半径は `m·z/2`
- **種類**: ウォーム `'worm'`（`teeth` は条数として常に 1）とホイール `'wormWheel'`。ウォームとかみ合えるのはホイールだけ、ホイールとかみ合えるのはウォームだけ（同じ大きさ）
- **新しい配置** `ShaftPlacement` の `'skew'`（ねじれた位置の 90°。S2-04 のねじ歯車でも使う）
  ```ts
  | {
      readonly kind: 'skew';
      readonly parentGearId: GearId;
      readonly childGearId: GearId;
      readonly axisStep: 1 | 2; // このシャフトの軸 = 親の軸を x → y → z → x の順に axisStep 回進めた軸
      readonly side: 1 | -1;
    }
  ```
  - `axis` は持たない（design.md §4）。このシャフトの軸は `axisStep` で親の軸から決まり、`Layout.shafts[id].axis` に出す。軸を進める関数は S2-02 の `'bevel'` と同じもの（`stepAxis`）を使う。先にあればそれを使い、なければここで `core/math` などに作る
  - 2 つの軸のどちらとも直交する 3 本目の軸を u とし、子の中心 = `親の中心 + (r_親 + r_子)·side·u`（r はピッチ円半径。ウォームは `5m`）。`axisStep` 2 通り × `side` 2 通りで、親 1 枚につき 4 か所
  - ウォームの中心は区画の中央（= 歯のある部分の中央）。ホイールの中心は歯幅の中央（§4 の式どおり）。子の `offset` は 0 としてシャフトの原点を逆算する
  - 位置は離散なので、外周の角度の円弧ハンドルは出さない
  - **S2-04 でも使う**: S2-04（ねじ歯車。S2-03 に依存する）は、ここで作る `'skew'` の配置・候補の仕組み・拘束の式をそのまま使い、歯車の組み合わせを足すだけにする。そのため、種類に依存しない部分（配置の解決、4 か所の列挙、`s` の計算）は、ウォームとホイールに決め打ちしない形で作る
- **候補**: ウォームを選ぶとホイールの候補（中・30 歯など S1-18 の既定の歯数）を、ホイールを選ぶとウォームの候補を、上の 4 か所のうち干渉しないものから出す。同じ軸の候補で `'worm'`・`'wormWheel'` を作れるようにする
- **偶然のかみ合い（contact）**: ウォームとホイール（同じ大きさ）で、軸が直交し、2 つの中心を結ぶ線が両方の軸に直交し、その長さが `r_ウォーム + r_ホイール` と `MESH_DISTANCE_EPS` 以内
- **位相**: ホイールの歯溝の中心が、接点でウォームの歯（ねじ山）の中心と重なるように、子（または親）の `basePhase` を決める。ウォームの位相はねじ山が軸方向に進む量と同じに扱う（回転角 2π でねじ山が `π·m` 進む）
- **拘束**（ねじれた位置の組の共通式。S2-04 でも使う）
  ```
  z_b·ω_b + s·z_a·ω_a = 0,  s = (e_a × u_ab)·e_b
  ```
  - e は各シャフトの軸の単位ベクトル、`u_ab` は a の中心から b の中心への単位ベクトル。a と b を入れ替えても s は変わらない
  - ウォームでは z = 条数（1）。右ねじのウォームと右ねじれのホイールのねじ山の向きから導いた式
  - 例: ウォームの軸 x、原点。ホイールの軸 z、中心が −y 側 → s = −1 → `ω_ホイール = ω_ウォーム × 1 / z`（同じ符号）。+y 側 → 逆の符号
- **セルフロック**（要件 §5: ホイール側から駆動しようとすると、強さに関係なくロック）
  - ウォームのかみ合いを **一方通行の拘束** として扱う。ウォーム側はホイール側の影響を受けず、ホイール側はウォームの動きに無限の強さで従う
  - 解き方（連結成分ごと）
    1. ウォームのかみ合いを除いたかみ合いでつながる部分を「区画」とする
    2. ウォームのかみ合いを「ウォームの区画 → ホイールの区画」の有向辺とし、区画の有向グラフをトポロジカル順に解く
    3. 入ってくる辺のない区画は、段階 1 と同じ力のつり合いで解く
    4. 入ってくる辺のある区画は、上流で決まったウォームの ω から求まるホイールの ω を **規定値（手で回すのと同じ無限に強い拘束）** として加えて解く。区画内のモーターは従わされる（逆向きなら `backDriven`）
    5. 有向グラフに閉路がある場合は、閉路に含まれる区画をまとめて 1 つの区画とし、その中のウォームのかみ合いは通常の（双方向の）拘束として扱う
  - **ロックの条件**（理由 `'wormBackDrive'`）
    - 規定値がすべて 0（上流のウォームが止まっている）の区画に、トルクを出しているモーターがあり、解いた ω がその区画で `LOCK_OMEGA_EPS` 未満
    - 手で、入ってくる辺のある区画のシャフトをつかんだ（手と上流のウォームの両方が規定値になる。手の動きに関係なく常にロック）
    - ロックしたら、§6 のとおり連結成分全体を ω = 0 にする。`LockInfo.reason` は `'wormBackDrive'`（design.md §6 で段階 2・3 に足すと決めてある名前）
  - 区画をまたいで解いた ω も、連結成分全体の拘束 `C ω = 0` を満たす。§6 の角度の積分（`ω = N q` で q を積分する）はそのまま使える（ω から q を求めて積分する）
- **形状**
  - ウォーム: 軸方向断面が圧力角 20° の台形（ラックの歯形）のねじ山を、右ねじのらせんに沿って掃いた形。両端は面取りした円柱で閉じる
  - ホイール: 進み角 γ と同じねじれ角の、右ねじれのハスバ歯車（S2-01 のねじり押し出しを使えれば使う。この依存はないので、なければ同じ式で作る）。のど（ウォームを抱く凹み）は省略する
  - 形状データのキーはウォームが `(種類, 大きさ)`、ホイールが `(種類, 大きさ, 歯数)`
- **干渉判定**: ウォームは半径 `5m + m`、長さ `5πm` の円柱、ホイールは歯先円の円柱で近似する。かみ合っている組は除く
- **表示**: 段階 1 と同じ材質（材質の違いは S2-05）。ねじ山の進む向きとホイールの回る向きが見た目で一致すること
- **保存**: シーンの検証で `'worm'`（`teeth === 1`）・`'wormWheel'`・`'skew'` を受け付ける。`version` は 1 のまま

### Vitest
- [ ] `resolveLayout(worm-basic)`: W の中心 `[16, 80, 0]`。H のシャフトの軸 `'z'`、H の中心 `[16, 40, 0]`（80 − (10 + 30)）、H のシャフトの原点 `[16, 40, -4]`。`meshes` に `kind: 'worm'`。`interferences` が空
- [ ] 運動: `worm-basic`（W 60 rpm = 2π rad/s）→ H は `2π/30` rad/s（= 2 rpm、同じ符号）
- [ ] 運動: `side: 1`（H の中心 `[16, 120, 0]`）→ H は `-2π/30` rad/s
- [ ] 区画の幅: 小・中・大のウォームで 16・32・48。`offset` 4 のウォームの中心は原点から 20（中）
- [ ] `s` の対称性: a と b を入れ替えても係数から求まる比が同じ
- [ ] 逆駆動: `worm-backdrive` → ロック（理由 `'wormBackDrive'`）、全シャフトの ω = 0
- [ ] 逆駆動（どの強さでも）: H 側のモーターを 大・120 rpm にしてもロック
- [ ] 両側にモーター: W に 小 60 rpm、H に 大 15 rpm（W が回すホイールの向きと逆向き）→ ロックしない。W は 2π rad/s（無負荷のまま。ホイール側の影響を受けない）、H は `2π/30`、H のモーターが `backDriven` に入る

- [ ] 閉路: 2 つのウォームで区画 A → B、B → A と閉じた機構 → まとめて 1 区画として解き、ギア比が合わなければ段階 1 の矛盾でロック
- [ ] 角度の積分: `worm-basic` を dt = 1/60 で 60 回積分 → W の角度 2π、H の角度 `2π/30`（ずれが 1e-9 未満）
