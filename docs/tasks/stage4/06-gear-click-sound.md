# S4-06 モーターのうなりをやめ、歯車のカタカタという音にする

## 目的
今の音は、モーターの「ジー」といううなりと連続音が目立つ。歯車らしいカタカタ・コトコトという粒の音にし、速さで高さが変わるようにする。

## 範囲
- 調査で分かった今の作り
  - 音はすべて Web Audio の合成（`src/audio/`）。値は `src/core/audio-model/index.ts` の純粋な関数で求める
  - かみ合いの音: 歯の通過頻度 `z·|ω|/2π`。15 Hz 未満はクリック、以上は連続音（30〜2000 Hz）。音色は `MESH_TIMBRES`（index.ts:128）。音源は最大 16（`mesh-voice.ts`、HRTF の `PannerNode`）
  - モーターのうなり（`motor-hum.ts`）: のこぎり波 + ローパス、基本 220/140/90 Hz × 速さ。負荷で音量。「ゴリゴリ」の帯域雑音つき。最大 4
  - 背景（`background.ts`）: 個別に鳴らさない組をまとめた持続音
  - テーマ: `THEME_AUDIO_MATERIAL`（`src/core/theme.ts:6,13`）で `'metal' | 'wood'`
- モーターのうなり（のこぎり波）を取り除く。過負荷のゴリゴリ音、ロック・ラック端の音（`lock-sound.ts`）は残す
- かみ合いの音は、速さによらず粒の音（カタカタ）にする。15 Hz での連続音への切り替えをやめる
  - 粒を打つ回数は歯の通過頻度に従い、上限（例: 毎秒 40 回）を超えたら間引く。間隔に少し揺らぎを入れ、ブーという音にしない
  - 粒 1 つの高さ（共鳴フィルタの中心周波数）は、回転が速いほど高くする（単調に増える）
- テーマ: metal は硬く高めのカタカタ、wood は柔らかく低めのコトコト
- 背景の持続音も、粒の音を重ねたざわざわに置き換える
- 音量のスライダーは足さない（ミュートのまま）
- 空間（位置・パンニング）、音源の数の上限、音源の選び方は今のまま

## 範囲外
- 録音した音（サンプル）を使うこと
- 音量の設定

## 作るもの
- `src/core/audio-model/`
  ```ts
  export function clickRate(toothPassHz: number): number; // 毎秒の粒の数（上限あり）
  export function clickPitch(toothPassHz: number, material: AudioMaterial): number; // 粒の中心周波数（Hz）
  ```
  - `MESH_TIMBRES` の連続音（`hum`）の欄の整理、材質ごとの粒の音色
- `src/audio/`: 粒の音の発音（`mesh-voice.ts`・`background.ts`）、`motor-hum.ts` のうなりの削除
- **design.md の書き換え**: 音の節（連続音への切り替えの廃止、うなりの廃止、粒の音）、§10 の `getAudio` の中身が変わるならその記述

## 受け入れ条件
- [ ] モーターを回しても「ジー」といううなりが鳴らない
- [ ] かみ合いの音は、遅くても速くても粒の音（カタカタ）に聞こえる
- [ ] 速く回すほど粒の音が高くなる
- [ ] 真鍮のテーマと木製のテーマで音色が違う（カタカタ／コトコト）
- [ ] 過負荷・ロック・ラック端の音は前と同じく鳴る

## テストケース
### Vitest
- [ ] `clickRate`: 歯の通過頻度 5 Hz → 5、1000 Hz → 上限以下
- [ ] `clickPitch`: 歯の通過頻度について単調に増える
- [ ] `clickPitch` の値が metal と wood で違う（metal が高い）
- [ ] モーターの音源の値に、うなりの周波数が含まれない（過負荷の雑音は含まれる）
### Playwright
- [ ] `__gearSim` の音の状態（`getAudio`）で、回っているかみ合いの音源が粒の音として出ている

## 人が手で確かめる項目

- テーマごとの音色の違い
