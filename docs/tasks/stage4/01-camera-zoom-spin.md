# S4-01 視点を回したあとのズームでカメラが回り込む不具合を直す

## 目的
視点をしばらく回したあとにホイールでズームすると、カメラがくるくる回ってからズームする（初期の視点に戻ってからズームしているように見える）。どれだけ回したあとでも、アニメーションでカメラが動くときに余計な回転をしないようにする。

## 範囲
- 原因（調査済み。`src/input/camera.ts` は `camera-controls` を包んでいる）
  - 回転は `controls.rotate(..., false)`（camera.ts:371 付近）、見守りモードも毎フレーム `controls.rotate(delta, 0, false)`（camera.ts:642 付近）。`rotate()` は方位角 `_spherical.theta` を正規化せずに足し込むので、回し続けると 3π などになる
  - ズームの `zoomAt()`（camera.ts:308-334）は `setPose` → `controls.setLookAt(..., animate)`（camera.ts:206-211）を呼ぶ。マウスのホイールでは `animate` が true
  - `setLookAt` は目標の `_sphericalEnd` を `setFromVector3` で作り直すので、θ が (−π, π] に入る。アニメーションは 3π → π のように補間され、1 周以上回る
  - `normalizeRotations()` は `setView`（camera.ts:341）でしか呼ばれていない。`lookFrom`（`fitAll`・`fitTo`・`dollyToPoint`、camera.ts:231）と `setPose` には無い
- 直し方: アニメーション付きで `setLookAt` を呼ぶ共通の入口（`setPose`・`lookFrom`）で、呼ぶ前に `controls.normalizeRotations()` を実行する。回すたびに正規化する案はとらない
- 対象の操作（すべて回り込まないこと）: マウスのホイールのズーム、F（全体表示）、選んだものに合わせる表示、「ここに寄る」、見守りモード中のズーム

## 範囲外
- カメラの操作方法・速さ・アニメーションの長さの変更
- ドラッグ中の回転の扱いの変更

## 作るもの
- `src/input/camera.ts`: `setPose`・`lookFrom` の、アニメーションする場合の正規化
- `src/input/camera.test.ts`（なければ作る）: 回り込みの再発を防ぐテスト

## 受け入れ条件
- [ ] 方位角を 2 周以上回してからホイールでズームしても、カメラは回り込まずにその場でズームする
- [ ] 同じ状態から F・選んだものに合わせる表示・「ここに寄る」を使っても回り込まない
- [ ] 見守りモードで長く回したあとにズームしても回り込まない
- [ ] 回り込まない以外の、ズームの結果（最終の位置・注視点）は変わらない

## テストケース
### Vitest
- [ ] 方位角を 4π 回した状態で `zoomAt` を呼ぶ → アニメーションの途中のどの時点でも、方位角の変化が π 以内
- [ ] 方位角を −5π 回した状態で `fitAll`（`lookFrom`）を呼ぶ → 同上
- [ ] 回していない状態の `zoomAt` の最終の位置・注視点が、修正の前と同じ
### Playwright
- なし（何周ものドラッグを再現するテストは不安定になるため）

## 人が手で確かめる項目
- 視点を何周も回してからホイールでズームし、回り込まないこと
- 見守りモードを 1 分ほど回してからズーム・F・「ここに寄る」を使い、回り込まないこと
