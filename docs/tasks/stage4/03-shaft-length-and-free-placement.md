# S4-03 シャフトの長さを持たせ、伸縮とシャフト上の好きな位置への配置

## 目的
今はシャフトを伸ばすのに「歯車を置く → 同じシャフトにもう 1 枚置く → どちらかを軸方向に動かす」という手順が要る。これを「シャフトを伸ばす → シャフト上の好きな位置に歯車を置く」にする。

## 範囲
- 調査で分かった今の作り
  - シャフトは長さを持たない（`Shaft = { id, placement }`、`src/core/scene/types.ts:23`）。長さは `spanOf(gears)`（`resolve.ts:1188-1215`）が、各歯車の `[offset − 4, offset + width + 4]`（`SHAFT_END_MARGIN`）の最小・最大から求める（内歯車・かさ歯車は補正あり）。歯車の無いシャフトは ±`EMPTY_SHAFT_HALF_LENGTH`（10）
  - 歯車の `offset` は `AXIAL_SNAP` = 4 mm の倍数で自由に変えられる（`setGearOffset`、`commands.ts:1181-1195`）。ただし親とかみ合う歯車（mesh・bevel・skew・planet・rack の `childGearId`）は拒否される
  - 軸方向のハンドルは `src/input/handle-drag.ts:37`（`axialOffsetFromDrag`）、`src/render/handles.ts:179`
- **シャフトの長さ**: `Shaft` に軸方向の範囲（例: `span: [start, end]`、4 mm の倍数）を持たせ、`spanOf` で長さを求めるのをやめてこの値を使う
  - 歯車の範囲（余白込み）がシャフトの範囲からはみ出す状態は、検証で弾く
  - 既存の編集（歯車を足す・動かす・歯数を変える）で歯車がはみ出すときは、シャフトを自動で伸ばす
- **伸縮**: シャフトを選ぶと両端につまみを出し、ドラッグで 4 mm 刻みで伸縮する
  - 載っている歯車の範囲（余白込み）より短くはできない
  - 最大の長さは決めない。ほかの部品とぶつかるところで止める
  - 伸縮は 1 回の編集として Undo/Redo できる
- **シャフト上の好きな位置に置く**: パレットで種類を選んだ状態でシャフトにマウスを乗せると、半透明の歯車がカーソルに合わせて軸に沿って 4 mm 刻みで動く。クリックでその位置に置く
  - 同じシャフトのほかの歯車やほかの部品と重なる位置では赤く表示し、置けない
  - パレットがラック・遊星のときはシャフトの上に出さず、「ラック／遊星は歯車の周りの候補から置きます」という注記を出す
  - これに置き換えて、同じ軸の両端の候補（`candidates.ts:350-395`）は無くす
- 親とかみ合う歯車を動かせない制限は今のまま
- **保存形式 version 4**
  - `CURRENT_SAVE_VERSION = 4`。`MIGRATIONS[3]`（version 3 → 4）で、各シャフトに今の `spanOf` で求めた範囲を入れる
  - S4-05 のために、歯車の厚さ `width` を **省略できる欄** として version 4 の形式に入れておく（読むときに無ければ大きさごとの値 `GEAR_SIZES` を使う）。S4-05 では version を上げない
  - version 1 → 2 → 3 → 4 と順に移行できる
- モーターの位置（`sync.ts:100-103`、`span[0] − MOTOR_GAP − box/2`）は、シャフトの範囲の端を使う
- 国際化: つまみ・注記・拒否の理由（日・英）

## 範囲外
- 起点のシャフトを歯車なしで置くこと（S4-04）
- 歯車の厚さを変える UI（S4-05）
- 親とかみ合う歯車の軸方向の移動

- **design.md の書き換え**: §4（シャフトの範囲、`width`）、§5（同じ軸の候補の廃止、シャフト上の配置）、§9（version 4）

## 受け入れ条件
- [ ] シャフトの両端のつまみで、4 mm 刻みで伸縮できる。歯車より短くはできず、ほかの部品にぶつかるところで止まる
- [ ] パレットで種類を選んでシャフトにマウスを乗せると、半透明の歯車が軸に沿って動き、クリックでその位置に置ける
- [ ] 重なる位置では赤くなり、置けない
- [ ] 同じ軸の両端の候補は出ない
- [ ] version 3 以前のファイルを開くと、シャフトの長さが前と同じになる
- [ ] 伸縮と配置は Undo/Redo できる

## テストケース
### Vitest
- [ ] version 3 のファイルを移行 → 各シャフトの範囲が移行前の `spanOf` と同じ
- [ ] version 1 のファイルを 4 まで移行できる
- [ ] `width` の無い version 4 の歯車を読む → 大きさごとの値になる
- [ ] 伸縮のコマンド: 歯車の範囲より短い → 拒否。ほかの部品とぶつかる → 拒否。4 mm の倍数でない → 拒否
- [ ] シャフト上の位置を指定して歯車を足す: 空いている位置 → 置ける。重なる位置 → 拒否
- [ ] 歯車を足してシャフトからはみ出す → シャフトが伸びる
- [ ] 同じ軸の候補が `listGrowCandidates` に出ない
### Playwright
- [ ] シャフトを選んで端のつまみをドラッグ → `__gearSim` のシャフトの範囲が伸びる
- [ ] パレットで平歯車を選び、伸ばしたシャフトの途中をクリック → その位置に歯車が置かれる
