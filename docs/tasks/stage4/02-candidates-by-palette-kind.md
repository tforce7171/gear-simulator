# S4-02 生やす候補をパレットで選んだ種類だけにする

## 目的
歯車を生やすとき、候補がたくさん出て選びにくく、置けない候補もある。候補を「左のパレットで選んだ種類の歯車ができるもの」だけにし、表示した候補は必ず置けるようにする。

## 範囲
- 調査で分かった今の作り（`src/core/layout/candidates.ts` の `listGrowCandidates`（:156）、`src/app/grow.ts` の `candidatesFor`（:34-54））
  - 外周の 8 方向（`PERIMETER_CANDIDATE_COUNT`、45° おき）の種類は親から決まる（`meshPartnerShape`）。パレットの種類は見ていない
  - パレットの種類を使うのは、同じ軸の両端の 2 つ（:350-395）と、内歯車のときの `'enclose'`（:225-255）だけ
  - `'planetary'` の候補（:258）は、親が平歯車なら毎回出る。ラックの候補（:262-264）4 つも、親が平歯車なら毎回出る
  - 候補は `resolveAddition`（:173-180）の差分の干渉判定でふるい、クリックで `growCommand` → `store.dispatch`（`interactions.ts:575-583`）
- 候補の絞り込み: 置くとパレットで選んだ種類の歯車ができる候補だけを出す。例: パレットが平歯車、親が平歯車 → 外周の平歯車 8 方向と同じ軸の 2 つだけ（遊星・ラックは出さない）
- パレットの「生やす歯車の種類」に「ラック」と「遊星」を足す。ラック・遊星の候補は、それを選んだときだけ出す（アイコンは S4-08）
- 親とかみ合えない種類を選んだとき（例: 親が平歯車でウォームを選んだ）: 外周の候補は出さず、同じ軸の候補だけを出す。「この歯車とかみ合えるのは〇〇です」という注記を 1 行出す
- 「置けないことがある」の原因を突き止めて直す。表示した候補は、どれをクリックしても必ず置ける（コマンドが拒否しない）。疑わしい点: `resolveAddition` と、コマンド側の判定（`resolveLayout` など）の食い違い、候補が歯車より先に拾われること（:225 の注記）
- 外周の候補は 8 方向のまま
- 国際化: ラック・遊星の種類名、かみ合えないときの注記（日・英）

## 範囲外
- 同じ軸の両端の候補の廃止（S4-03 でシャフトの上で位置を選ぶ方式に置き換える）
- パレットのアイコンと並べ方（S4-08）
- 起点のシャフトの最初の歯車の種類（S4-04）

## 作るもの
- `src/core/layout/candidates.ts`: パレットの種類での絞り込み、かみ合えないときの扱い
- パレットの種類の一覧（`GEAR_KIND_LIST` か、パレット専用の一覧）にラック・遊星を足す。歯車の `GearKind` そのものに足すかは実装で決め、design.md に書く
- `src/ui/palette.ts`: ラック・遊星のボタン、注記
- 置けない候補の原因の修正

## 受け入れ条件
- [x] 候補は、パレットで選んだ種類の歯車ができるものだけが出る
- [x] ラック・遊星は、パレットで選んだときだけ候補に出る
- [x] 親とかみ合えない種類を選ぶと、同じ軸の候補だけが出て、理由の注記が出る
- [x] 表示した候補は、どれをクリックしても置ける
