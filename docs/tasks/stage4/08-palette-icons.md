# S4-08 パレットにアイコンを付ける

## 目的
左のパレットは文字だけで、どの歯車か分かりにくい。歯車の絵を付けて、見て選べるようにする。

## 範囲
- 調査で分かった今の作り: `src/ui/palette.ts`（`h()` で DOM を組む）と `src/ui/palette.css`。区分は大きさ（S/M/L、`palette-size-*`）、生やす歯車の種類（`GEAR_KIND_LIST`。S4-02 でラック・遊星を足した）、置く部品（起点のシャフト）。画像の資産は無い（palette.css:110-135 の CSS の絵だけ）
- アイコンは SVG で描き、コードに入れる（例: `src/ui/icons.ts`）。色は `currentColor` で、テーマ・文字の色に従う
- アイコンを付けるもの
  - 歯車の種類: 平・はすば・かさ・ウォーム・ウォームホイール・ねじ・内歯車・ラック・遊星
  - 起点のシャフト（CSS の絵を SVG に置き換える）
  - 大きさ S/M/L: 同じ歯車の絵を小・中・大で描く
- 並べ方: 2 列の格子。アイコンを上、文字を下にする。文字は残す
- 選んでいる状態、押せない状態の見た目は今の規則に合わせる

## 範囲外
- 3D のサムネイル
- パレットの区分・項目の追加（S4-02 で済み）

## 作るもの
- `src/ui/icons.ts`: 種類ごとの SVG
- `src/ui/palette.ts`・`palette.css`: アイコン入りのボタン、2 列の格子

## 受け入れ条件
- [ ] パレットのすべての歯車の種類・起点のシャフト・大きさのボタンにアイコンがある
- [ ] アイコンの色がテーマ・選択の状態に合わせて変わる
- [ ] 文字のラベルも残っている

## テストケース
### Vitest
- [ ] パレットの種類の一覧のすべてにアイコンがある（追加漏れを型か一覧で検出する）
### Playwright
- [ ] 見た目のテスト（`e2e/visual/`）: パレットの基準の画像を撮り直す
- [ ] 既存のパレットの操作のテストが、アイコン入りのボタンでも通る

## 人が手で確かめる項目
- アイコンを見て、どの歯車か分かること
