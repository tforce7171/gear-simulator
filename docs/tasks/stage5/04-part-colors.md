# S5-04 歯車・ラック・キャリア・アンカーの色を部品ごとに選べるようにする

## 目的
今は部品の質感がテーマ（真鍮・木）と部品の種類だけで決まり、作品の中で色を変えられない。部品ごとに色を選べるようにし、金属のシルバーとメタリックブルー、木のダークオークを足す。

## 範囲
- 色を選べる部品: 歯車（すべての種類）・ラック・キャリア・アンカー。シャフトとモーターは今どおりテーマで決まる
- シーンの部品に、省略できる `color?: PartColor` を足す
  - `PartColor = 'brass' | 'silver' | 'metallicBlue' | 'wood' | 'darkOak'`
  - 省略（＝「自動」）のときは今どおり、テーマと種類で決まる質感（`gearLook(theme, kind)`・`PART_KIND_MATERIALS`）
- 選べる色はテーマの系統で変わる
  - 真鍮のテーマ（金属）: 自動・真鍮・シルバー・メタリックブルー
  - 木のテーマ: 自動・木・ダークオーク
  - 今のテーマと違う系統の色を持つ部品（例: 木のテーマでシルバー）は、その部品の「自動」の質感で描く。保存された値は消さない。プロパティでは「自動」が選ばれているように見せず、今の値が別の系統であることが分かるようにする（例: どれも選ばれていない状態＋注意書き）
- 質感
  - 真鍮: 今の `brass`
  - シルバー: 今の `steel`（0xb9bec4）と同じ
  - メタリックブルー: 金属（metalness 1）で、つやのある青。値は見て決める
  - 木: 今の `lightWood`
  - ダークオーク: 今の `darkWood`（赤茶）とは別の、黄みのあるこげ茶（0x4a3220 前後）。木目を `lightWood` よりやや強く
- 操作: プロパティパネルに色の欄（色見本のボタンを並べる。`role="radiogroup"`）。変更は編集コマンド（例: `setPartColor { target, color | null }`）で、Undo/Redo できる
- 生やした歯車（候補から作った歯車・ラック・遊星の部品）は、元の部品の `color` を引き継ぐ。起点のシャフトから最初に置く歯車と、床に置く部品は「自動」
- 選択・ロック・干渉の強調表示は、色を付けた部品でも今と同じように見える
- 音は変わらない（テーマで決まる）
- 国際化: 色の名前・欄の名前・別の系統の注意書き（ja / en）。括弧書きは使わない（S5-02 の決まり）

## 範囲外
- 自由な色の指定（カラーピッカー）
- シャフト・モーター・床の色
- 歯車ごとの音の材質

## 作るもの
- `src/core/scene/types.ts`: `PartColor`、歯車・ラック・キャリア・アンカーの `color?`
- `src/core/scene/parse.ts` / `validate.ts`: `color` の読み込みと検証（知らない値 → 検証エラー）
- `src/core/edit/commands.ts`: 色を変えるコマンド（add-edit-command スキルを使う）。生やすコマンドで `color` を引き継ぐ
- `src/render/themes.ts`: `PartColor` ごとの質感、テーマの系統と色の対応、「自動」への戻し
- `src/render/` の SceneSync: 今は同じ種類の歯車が 1 つの材質を共有している（`setBaseMaterials` の `gear: Record<GearKind, …>`）。種類 × 色ごとに材質を持つ形にする。色が変わったときに描き直されること（CLAUDE.md の `invalidate` / `SceneSync.version()` の注意）
- `src/ui/properties.ts`: 色の欄
- **design.md の書き換え**: §4（`color`）、テーマと質感の節、§7（コマンド）、§9（保存形式の説明）

## 関連箇所
- テーマの定義: `ThemeId`・`THEME_AUDIO_MATERIAL`（`src/core/theme.ts`）、`GEAR_MATERIAL_LOOKS`・`GEAR_KIND_MATERIALS`・`PART_KIND_MATERIALS`・`gearLook`（`src/render/themes.ts`）
- 描画を変える前に design.md §7 の「描画を軽くする仕組み」を読む。重さは `pnpm perf --headless` で main と比べる（材質の数が増えるため）
- 保存形式: version は上げない（`color` は省略できる。省略は今の見た目と同じ意味）。`e2e/fixtures/*.json` は直さなくてよい
- 影響を受けるテスト: 生やすコマンドの Vitest（`color` の引き継ぎ）、`src/app/grow.test.ts`、テーマの見た目の e2e（`e2e/visual/` の `theme-*`）

## 受け入れ条件
- [ ] 真鍮のテーマで平歯車を選び、色をシルバー・メタリックブルーに変えられ、見た目に反映される
- [ ] 木のテーマでダークオークを選べ、今の暗い木（ウォーム）と見分けられる
- [ ] ラック・キャリア・アンカーにも色を付けられる。シャフト・モーターには色の欄が出ない
- [ ] 色を付けた歯車から生やした歯車が同じ色になる
- [ ] 真鍮のテーマでシルバーにした歯車は、木のテーマにすると木の自動の質感で描かれ、真鍮のテーマに戻すとシルバーに戻る
- [ ] 色は保存・読み込み・エクスポート・インポート・Undo/Redo で保たれる
- [ ] `color` のない既存の作品は今と同じ見た目

## テストケース
### Vitest
- [ ] 色を変えるコマンド: 歯車・ラック・キャリア・アンカー → 通る。シャフト・モーター → 拒否。知らない色 → `invalidValue`。`null` → `color` が消える
- [ ] 生やすコマンド: 親の `color` が子に入る。親が `color` なしなら子もなし
- [ ] テーマの系統と色の対応: 真鍮 × シルバー → シルバーの質感、木 × シルバー → 自動の質感
- [ ] `color` を持つシーンを保存・読み込み → 同じ値。知らない `color` を持つファイル → 検証エラー
### Playwright
- [ ] 平歯車を選び、色の欄でメタリックブルーを押す → `__gearSim` の歯車の `color` が `metallicBlue`。Undo → `color` なし
- [ ] 色を付けた歯車から候補で歯車を生やす → 新しい歯車の `color` が同じ
- [ ] 見た目の確認: 真鍮・シルバー・メタリックブルーの歯車を並べた場面と、木・ダークオークを並べた場面を撮り、Read で見る

## 人が手で確かめる項目
- メタリックブルーとダークオークの色味が、照明の当たり方を変えても狙いどおりに見えるか
- 選択・ロック・干渉の強調表示が、どの色の上でも見分けられるか
