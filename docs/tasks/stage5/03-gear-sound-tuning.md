# S5-03 金属の音を歯車らしく、木の音を重くする

## 目的
S4-06 のカタカタという音のうち、金属の音はオルゴールのように聞こえて歯車らしくない。木の音はおおむね良いが、もう少し重厚感がほしい。合成の値を調整する。

## 範囲
- 金属（`MATERIALS.metal`）: 硬く短いクリックに、ごく短い金属の余韻を付けた音にする
  - 音程感を弱める: 倍音の比を整数比から外す・数を減らす、帯域通過の Q を下げる（今は 10）、ノイズの割合を上げる
  - 余韻を大幅に短くする（今は倍音の減衰 25 / 18 / 12 ms）
  - 速く回ると粒が詰まり、「ジー」という連続音に聞こえる（`CLICK_RATE_MAX` までの粒の詰まり方で出す。足りなければ滑りのノイズを使う）
- 木（`MATERIALS.wood`）: 低い成分を足し、高い成分を少し削って重くする。余韻は伸ばさない
- 種類ごとの音色の倍率（`MESH_TIMBRES`）の関係は保つ（はすばは静か、ウォームは滑りの音、など）
- 音は今どおりテーマ（`THEME_AUDIO_MATERIAL`）で決まる。S5-04 で付ける歯車ごとの色は音に影響しない

## 範囲外
- 録音した音（サンプル）の利用
- 歯車ごとの音の材質、厚さによる音の変化
- 歯のない区間で音を止めること → S5-05

## 作るもの
- `src/core/audio-model/index.ts`: `MATERIALS` の値。必要なら `MaterialAudio` に欄を足す（例: 低い成分の帯域、倍音ごとの比）
- `src/audio/mesh-voice.ts`: 粒の合成。足した欄を使う
- **design.md の書き換え**: 音の節（材質ごとの値の表）

## 関連箇所
- `clickParams`・`clickPitch`・`MATERIALS`・`MESH_TIMBRES`（`src/core/audio-model/index.ts`）、粒の合成（`src/audio/mesh-voice.ts`）
- 背景の粒（`src/audio/background.ts`）も同じ材質の値を使うか確かめる
- 影響を受けるテスト: `src/core/audio-model/*.test.ts` のうち値を直に比べているもの
- 保存形式: 変えない
