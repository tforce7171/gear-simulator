# S5-05 欠け歯車でラックを往復させる

## 目的
ラックは同じ向きに送ると端に着いてロックするだけで、機構で往復させる手段がない。平歯車の一部の歯をなくした「欠け歯車」を作れるようにし、かみ合いが角度によって入ったり外れたりするようにする。これで、同じ軸の欠け歯車 2 枚と中間歯車で、ラックを自動で往復させられる。

```
 同じ軸 S に欠け歯車 A・B（歯のある弧を互いにずらす）
   面1: A ──────────────かむ── ラック（右へ）
   面2: B ── 中間歯車 ──かむ── ラック（左へ。中間歯車で向きが反転）
 ラックは面1 と面2 にまたがる幅にする
 歯数の条件: A の歯数 = B の歯数 + 2 × 中間歯車の歯数
```

## 範囲
### 欠け歯車の形とプロパティ
- 平歯車に 2 つの省略できる欄を足す
  - `toothCount?`: 残す歯数。1〜`teeth`。省略または `teeth` のときは普通の平歯車
  - `toothStart?`: 歯のある弧の始まり。1 歯単位（0〜`teeth − 1`）。省略は 0
- 歯はひと続きの弧として残す（とびとびの並びは作らない）。歯のない部分は歯底円の弧にする
- プロパティパネル: 平歯車に「残す歯数」と「歯の位置」の欄（どちらも［−］入力［＋］）。注意書きで往復の組み方（A ＝ B ＋ 2 × 中間）を案内する。括弧書きは使わない（S5-02 の決まり）
- 歯数を変えたときは、`toothCount` と `toothStart` を新しい歯数の範囲に収める
- 形のキャッシュのキー（`gearShapeKey`）に 2 つの欄を含める

### かみ合いの入り切り
- 欠け歯車を含むかみ合い（歯車どうし、歯車とラック）は、欠け歯車の今の角度で、歯のある弧が接点に来ているときだけかかる。来ていない間は、その組のかみ合いはないものとして扱う
  - 相手は、ほかのかみ合いやモーターから動かされなければ止まる（慣性はない）。手でも動かせる
- 入り切りの判定は、運動の 1 ステップの中で入る・外れる瞬間をまたいだら、ラックの端の処理（`rackEndFraction`）と同じように、その瞬間までだけ進めて区切る
- かみ合い直す瞬間に相手の歯と位相が合わないときは、その場でロックする。理由は新しい `LockReason`（例: `'toothClash'`）で、情報表示に「歯が合わない」と出す。置いた時点では警告しない
- 同時にかかったかみ合いが矛盾するとき（A とラック、中間歯車とラックが同時にかかるなど）は、今の `'contradiction'` ロック
- ラックが端に着いたら、今と同じように止まってロックする
- かみ合いのグラフは今、シーン（`Layout`）だけで決まりキャッシュされている。角度でかかるかみ合いの組が変わるので、グラフ・成分・基準の軸の選び方・`q` の引き継ぎ（design.md §6）をこれに合わせる。欠け歯車のないシーンでは、今と結果も重さも変わらないこと

### 音
- 欠け歯車を含むかみ合いの声は、かかっていない間は粒を鳴らさない（`computeMeshVoices` / `meshGrainTimes` の声に「かかっているか」を持たせる）
- かかっていないことを、ラックの端の音（`rackEndHits`）やロックの音として鳴らさない

### 見本
- 作品一覧から開ける見本「ラック往復」を足す: 小の大きさで A ＝ 36 歯、B ＝ 12 歯、中間歯車 ＝ 12 歯、ラックの幅 8 mm。A と B の残す歯数はどちらも 8 歯（A は 80°、B は 240° の弧。9 歯だと合わせて 360° になり、かかり始めと外れる瞬間が重なる）で、歯のある弧の間に、どちらもかからない短い区間ができる位置に置く
- 同じシーンを `e2e/fixtures/rack-reciprocation.json` に置き、e2e と見た目の確認に使う

## 範囲外
- 向かい合う 2 本の歯を持つラック枠（今回は今ある部品だけで組む）
- 往復の組み立てを自動で行う操作（中間歯車を自動で置くなど）
- 平歯車以外の欠け歯車（はすば・かさ・内歯車など）
- とびとびの歯の並び、ゼネバ機構
- ラックの端のばね・跳ね返り、慣性
- 左右の送りの長さが違ってラックが少しずつずれていくことへの注意や防止（仕組みどおりの動きとしてそのままにする）

## 関連箇所
- 調べて分かった今の作り
  - かみ合いのグラフは `meshGraphOf` / `anchoredMeshGraphOf`（`src/core/kinematics/motion.ts`）が `layout.meshes` と `layout.rackMeshes` から作り、`Layout` ごとにキャッシュしている。角度で変わるものは今、ラックの端のロック（`rackEndFraction`・`clampRacksIntoTravel`）だけ
  - 外周の候補で生やした中間歯車は、ラックに接する位置にあれば接触のかみ合い（`rackMeshesOf`、`source: 'contact'`）として拾われる。接触のかみ合いは今、位相を確かめていない（design.md §5「位相は問わない」）。欠け歯車のかみ合い直しで位相を確かめるので、この決まりを書き換える
  - 中間歯車を B から「ラックへ向かう向き」の候補で生やすと、A ＝ B ＋ 2 × 中間 のときちょうどラックに接する（外周の候補は 45° おき）
  - B を A と同じ歯数にすると、B 自身がラックの幅に入ってラックとかみ合ってしまう。B を小さくすれば当たらない（例の歯数で約 11 m のすき間）
  - ラックの干渉の外形は、送りの範囲全体を覆う円柱。幅を広げすぎると小さい歯車のシャフトに当たる（例では幅 8 mm で足りる）
  - 音の粒は「軸の角度 × 歯数」から出す（`toothPassTimes`）ので、手当てしないと歯のない区間でも鳴る
- 歯車の種類は足さない（平歯車の欄として持つ）ので add-gear-kind スキルは使わないが、その「型で拾えない落とし穴」（位相を回しながら確かめる、干渉の外形、性能の目安）は同じく確かめる
- 保存形式: version は上げない（2 つの欄は省略でき、省略は普通の平歯車と同じ意味）
- 影響を受けるテスト: 運動の Vitest（`src/core/kinematics/*.test.ts`）、`src/app/grow.test.ts`（新しい fixture の候補）、`pnpm test` の性能の目安（2 回流す）

## 受け入れ条件
- [ ] 平歯車の「残す歯数」を下げると、その分の歯がなくなった形で描かれる。「歯の位置」で歯のある弧が 1 歯ずつ回る
- [ ] 欠け歯車でラックを回すと、歯のある間だけラックが進み、歯のない間は止まる。止まっている間は音が鳴らない
- [ ] 見本「ラック往復」を開いてモーターを回すと、ラックが左右に往復し続け、ロックしない
- [ ] 歯のある弧が重なるように「歯の位置」を変えると、両方がかかった瞬間に矛盾でロックする
- [ ] かみ合い直す瞬間に位相が合わない配置では、その瞬間に `toothClash` でロックし、理由が出る
- [ ] 欠け歯車のない既存の作品は、動き・音・重さが今と同じ
