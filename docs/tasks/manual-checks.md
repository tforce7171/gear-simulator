# 人が手で確かめる項目

各タスクの「人が手で確かめる項目」と、エージェントの環境では確かめられない受け入れ条件（ブラウザでの目視、実機での計測など）をここに貯める。確かめたら「結果」を書く。

| タスク | 項目 | 確かめ方 | 結果 |
|---|---|---|---|
| S1-01 | ブラウザの入っていない環境でも Playwright が動く | Playwright のブラウザを入れていない環境（`~/.cache/ms-playwright` が無い）で `pnpm install` → `pnpm e2e:install` → `pnpm verify` が通ることを確かめる | |
| S1-01 | `pnpm dev` でブラウザに床のグリッドが出る | `pnpm dev` を起動し、表示された URL を実際のブラウザで開いて、暗い背景に床のグリッドが見え、ウィンドウの大きさを変えると追従することを目で確かめる | |
| S1-01 | `screenshots/empty-scene.png` に床のグリッドが見える | `pnpm e2e` のあと `screenshots/empty-scene.png` を開いて、床のグリッドが描かれていることを目で確かめる | |
| S1-04 | `pnpm dev` で 12 歯と 24 歯の平歯車がかみ合って回る | `pnpm dev` を開き、12 歯（モーターの箱が下に付いている方）が上から見て反時計回り、24 歯がその半分の速さで時計回りに回ることを目で確かめる | |
| S1-04 | 歯が重ならずにかみ合って回り続ける（位相が合っている） | `pnpm dev` でしばらく回し続け、かみ合う所で歯が重ならず、すき間も不自然に開かないことを確かめる。`pnpm e2e` のあとの `screenshots/two-spur.png` でも確かめる | |
| S1-04 | 歯形がインボリュートらしく見え、歯の向きの取り違え（裏返し）がない | `screenshots/two-spur.png` と `pnpm dev` で、歯の両側の歯面が外に向かって細くなる曲線で、左右対称に見えることを確かめる | |
| S1-09 | シャフトが歯車の両面から `SHAFT_END_MARGIN`（4 mm）ずつ伸びて描かれる | `pnpm dev` と `pnpm e2e` のあとの `screenshots/two-spur.png` で、両方のシャフトが歯車の上下に少しずつ突き出ていること（S1-08 までは歯車の厚みと同じ長さだった）を目で確かめる | |
| S1-13 | 回転・平行移動・ズームの速さが自然で、引っかかりがない | `pnpm dev` を実際のブラウザで開き、何もない所の左ドラッグ・右ドラッグ・Alt+左ドラッグ（回転）、中ドラッグ・Shift+右ドラッグ・Space+左ドラッグ（平行移動）、ホイール（カーソルの方へズーム）を試し、速すぎ・遅すぎ・飛び・引っかかりがないことを確かめる。平行移動はつかんだ所がカーソルについてくる向きであること | |
| S1-13 | ダブルクリック・F・Home の移り方がなめらか | `pnpm dev` で歯車の上・床の上をダブルクリック（そこへ寄り、距離が半分）、遠くへ動かしてから F・Home（全部が収まる）を押し、移り方がなめらかで不自然な回り込みがないことを確かめる | |
| S1-13 | Mac で Ctrl+クリック（右クリック扱い）の挙動に違和感がない | Mac の実機で `pnpm dev` を開き、Ctrl+クリックでブラウザ標準のメニューが出ないこと、Ctrl+ドラッグで回転になること、トラックパッドの 2 本指クリックでもメニューが出ないことを確かめる（メニューの中身は S1-29） | |
| S1-13 | 右クリックでブラウザ標準のメニューが出ない（Windows・Mac・Linux） | 各 OS の実機のブラウザで、キャンバスの上を右クリック（押して離す）・右ドラッグしてもブラウザのメニューが出ないことを確かめる（Linux の Chromium では自動テストで `contextmenu` の既定の動作が止められていることを確かめ済み。OS によって `contextmenu` が押したときと離したときのどちらで来るかが違うため） | |
| S1-15 | 文字の大きさ・余白・並びが整っていて、英語の長い文字列でもボタンが崩れない | `pnpm dev` を実際のブラウザで日本語と英語（`__gearSim.setLanguage('en')`）の両方で開き、ツールバーのボタンの文字が 1 行に収まって切れたり重なったりしないこと、パネルの見出しと案内文の余白が自然なことを確かめる。`pnpm e2e` のあとの `screenshots/ui-ja.png`・`screenshots/ui-en.png` でも確かめる | |
| S1-15 | 狭いウィンドウ（幅 1000px 前後）でも使える | `pnpm dev` でウィンドウの幅を 1000px 前後まで縮め、描画領域が残り、ツールバーのボタンが（はみ出す場合は横スクロールで）すべて押せる位置にあり、パネルが描画領域を隠さないことを確かめる | |
| S1-15 | トーストの見た目と位置が自然 | `pnpm dev` の開発者ツールのコンソールで `import('/src/ui/toast.ts').then((m) => { m.showToast('app.title', 'info'); m.showToast('app.title', 'error'); })` を実行し、描画領域の下寄りに 2 つ積み重なり（新しいものが下）、通知は 3 秒・エラーは 6 秒で消え、閉じるボタンでも消えることを目で確かめる | |
